# 手柄工具坐标操作与第六关节直控

右摇杆原先按卫星本体轴请求旋转，A/B 也通过笛卡尔旋转指令驱动机械臂。转腕后，摇杆方向不随夹爪改变，A/B 可能触发其他关节的 IK 运动。

新的右摇杆俯仰/偏航指令使用实测 `sarm_ee` 工具坐标。仿真端将工具角速度转换到卫星本体系，再交给原有 IK。A/B 单独输入直接推进 joint6 的参考位置，跳过 IK 与肘部姿态偏好；与摇杆同时输入时在 IK 关节速度上叠加 J6 指令，再统一限制速度、位置和跟踪误差。

前端、后端安全缩放、数据模型、接收校验和控制协议同步新增工具角速度与 J6 通道。缺省字段为零，旧客户端继续使用卫星本体系旋转。急停、失焦、失联、deadman、准备动作和超时仍会清零新通道；松开 A/B 停止直接推进，换向从零加速。

验证覆盖纯 J6 不调用 IK、工具方向随腕部旋转、组合速度限幅、限位反向脱离、跟踪保护、旧协议和超时清零，以及浏览器按钮映射。基础 CI 保留纯安全、协议及速度合成检查；依赖 Basilisk 的五组遥操作用例在 ci-exclusions.json 中注明，并在独立原生进程运行，避免与离线 MuJoCo 同进程混载。

本次不改变键盘平移坐标或 UE 渲染协议。更新后重启后端和仿真场景并刷新网页；接触下的实际关节运动仍由动力学/PID 决定。操作映射与约束见 [手柄文档](../docs/GAMEPAD_TOOL_CONTROL.md)。
