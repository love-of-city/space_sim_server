# 手柄末端相对操作（2026-09-23）

| 输入 | 动作 |
| --- | --- |
| 左摇杆 | 卫星本体系 X/Y 平移 |
| LT / RT | 卫星本体系下降 / 上升 |
| 右摇杆上 / 下 | 相对夹爪自身方向抬头 / 低头 |
| 右摇杆左 / 右 | 相对夹爪自身方向左转 / 右转 |
| A / B | joint6 负方向 / 正方向旋转，最高 0.5 rad/s（约 28.6°/s） |
| X / Y | 夹爪闭合 / 张开 |

标准 Gamepad/XInput 映射；连接后先回中，点击画面取得控制权。键盘原来的卫星本体系控制保持不变。新逻辑需要重启后端和仿真场景，并刷新网页；无需重新编译 UE。

右摇杆方向跟随实测 `sarm_ee` 工具坐标，不跟随主视口或自由相机。模型的局部 +Z 是腕部轴/夹爪指向，局部 +Y 为两指开合轴；摇杆上推绕局部 +Y 旋转，使指向转向局部 +X，右推绕局部 −X 旋转，使指向转向局部 +Y。A/B 转腕后，后续摇杆的俯仰/偏航也随工具旋转。右摇杆仍由 IK 协调关节，尽量保持末端位置。

单独按 A/B 不调用 IK 或肘部姿态偏好，只推进 J6 的目标，J1–J5 的目标保持；实际机械臂仍由动力学和 PID 驱动，接触时不能保证其他关节完全不动。A/B 和摇杆同时输入时，在 IK 关节速度上叠加 J6 指令，再统一执行速度、位置及跟踪误差保护。松开 A/B 立即停止直接目标推进；换向从零向新方向加速，避免保留旧方向输入。

指令链路新增浏览器 `angular_control_frame`、归一化 `joint6_velocity`，以及仿真协议中的 `end_effector_angular_velocity_tool_rad_s`、`joint6_velocity_rad_s`。旧包缺省新字段为零，原有 body 角速度字段始终表示卫星本体系，不将工具坐标冒充本体系。急停、准备动作、失焦/断连/超时继续清零运动指令；关节限位、力矩及跟踪保护仍然生效。

自动化验证覆盖 A/B 独立输入、换向/松键、当前工具朝向转换、混合指令限速、跟踪阻塞、旧协议兼容与超时停控。实际手柄手感和接触下运动需在重启场景后试用。
