# Near23 可复现工作灯

正式 `near23_vbar_v1` 相机配置显式声明右相机的 `inspection-1500cd-v1` 工作灯。该灯在场景加载时创建，不依赖 Pixel Streaming 连接或浏览器开关；同一相机后续打开视频流时复用该灯。声明期间浏览器只能查询，不能更改它。未声明灯的其他相机继续使用原有行为。

参数沿用原生相机预览工作灯：1500 cd、10 m 衰减半径、35° 内锥半角、65° 外锥半角，安装在相机光学原点并沿光轴发光，不投射阴影。这是现有仿真照明模型，不能解释为已选型或已标定的飞行硬件；未建模灯具质量、功耗或热耗。未增加全局补光，也不改变相机内外参、导航阈值或航天器状态。

变更起因是一次保留的 7 km 全流程失败：离线入口没有创建原先由视频流创建的工作灯，在约 7144–7160 s 进入地影时失去标记。原始失败回合没有保存图像；随后在最终物理状态做零积分的静态复现，新旧渲染版本均得到接近全黑的真实 UE 图像。静态复现只用于诊断，不能充当连续飞行验收。

UE 每张图像的私有元数据记录实际创建的工作灯、是否可见、光度单位、强度、范围、锥角和相机安装关系。图像求解器仍只接收 RGB 与静态标定；工作灯元数据与相机真值均不进入导航结果通道。正式验收必须保留实际回执，并重新运行不中断的全流程。单独存在 `native_work_lights_ready.json` 文件不能证明图像采样时的照明状态。

当前变更需要云端原生 UE 构建、自动化测试、相同保存状态的有灯/无灯对照，以及正式入口连续全程验收。失败证据保持原样，照明模型变更以本次提交与配置哈希区分。
