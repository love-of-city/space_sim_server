## 适配与问题处理

- Linux clang 将自动化测试中复制 FString 的 range-loop 警告作为错误；将循环变量改为 `const FString&`，Linux 编辑器目标和 Runtime `.so` 编译成功。同一修改在 Windows 增量编译成功；Windows 首轮遇到全局 UBT mutex 权限问题，确认无其他构建进程后使用 UBT 的 `-NoMutex` 选项完成本次验证，没有修改系统权限或终止其他进程。
- UE 项目显式设置 Linux `SF_VULKAN_SM6`，移除默认 SM5，与 Windows 的 SM6 渲染功能级别对应。
- GPU 验收脚本复用跨平台 UE 路径解析器，仅在 Windows 传入隐藏窗口参数；增加 `SPACE_SIM_UE_STARTUP_TIMEOUT`（默认 60 秒，部署冷启动可设 600 秒，范围 0–1800 秒），不放宽图像或同步断言。
- 131 个场景网格完成实际 UE 导入和配置确认；保留源几何、法线与现有缩放策略。
- 首次 RGB 检查因 60 秒启动时限失败；延长冷启动等待后，协议和帧配对检查通过，但图像呈灰色棋盘格，颜色断言失败。保存失败图像后确认几何位置正常，执行 Linux 项目的 DDC 填充。命令成功结束，0 个错误、3 个警告；完成后同一颜色/朝向断言通过，未修改 RGB 通道转换或降低图像验收标准。
