# 双目靶标与陀螺抓取整合

以统一仓库 main `94bdd75`（保留刘丹旭 PR #35、相机投影 PR #36、V-bar PR #34）为基准，接入本地已验证的23块多尺寸靶标和抓夹前置双目；保留原腕部单目默认行为。新模式明确选择同一场景的相机、标定、靶标与预测抓取输入，防止渲染/算法使用不同机位。

图像通过独立进程解算，经静态手眼标定换算机构中心，再按曝光时刻与编码器/共享50 Hz陀螺对应。有图像时更新，缺图像时复用原自身运动预测，接触后复用闭爪与力控保持。没有加入目标真值作为抓取测量，也没有修改 V-bar、灯光、视场或分辨率。

实现、启用方法、验证及模型边界见[整合说明](../space_sim_server/docs/NEAR23_GYRO_CAPTURE_INTEGRATION_20261029.md)。完整动力学/图像试验的运行数据保存在忽略的 `run/near23_gyro_integration_20261029/` 下，不提交原图和日志。

随后合入main `6c53480`（采集）与 `3562567`（原单目/陀螺复现入口），逐项保留新增功能；本模式显式保留原灯光，其他采集场景的全局补光不变。诊断工具移至 `tools/diagnostics/`。main新增摩擦统计需要读取有效原生句柄，旧基准脚本在关闭动力学后仍请求统计；独立工具缓存关闭前成功读取的快照，供旧脚本输出结果，不修改物理或读取已释放对象。

main `94bdd75`整合版的4 cm起点复验正常结束：1050组同曝光图像/真值零错配，42040个400 Hz接触记录中四爪承载且压盘力4.5–5.5 N连续20.10 s，最终4.999942 N。图像机构中心误差RMSE 0.188916 mm、最大1.535024 mm；严格评分通过。0.5 m起点影像也完成接近与10 Hz反馈20 s保持，但旧脚本收尾及混写接触日志不合格，不据此报告400 Hz全段验收通过。历史原始记录不改写。
