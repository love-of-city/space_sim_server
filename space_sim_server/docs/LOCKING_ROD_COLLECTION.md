# 锁紧杆旋松、放下及复位旋紧采集

任务名为 `locking_rod_cycle`，控制器版本为
`locking-rod-cycle/2-coaxial-latch`。这项任务操作的是杆端的防脱紧固件
`fastener`，杆 `locking_rod` 始终绕原有底部铰链摆动，不会从底座中拔出。

完整顺序为：接近时同步转腕和张爪，扣住紧固件原有的两侧卡口，同轴旋松，
停稳并松爪换成放倒抓姿，再将杆绕底部铰链放入 `limit_clip` 卡扣。松爪
撤开后重新抓取并扶起；随后松爪换回同轴卡口抓姿，回挂钩处旋紧并撤离。

旋拧抓姿的闭合轴为紧固件局部 Y，腕部旋转轴沿紧固件局部 Z，夹持 TCP
位于局部 Z=-5 mm。原生接触点必须实际落在原 CAD 两侧卡口区域；只有
六角头外表面或夹爪附加颈部接触不能证明扣合。旋拧必须在这类双侧扣合
确认后开始；不会继续使用腕轴倾斜约 60° 的放倒抓姿旋拧。

放倒和扶起使用独立支撑抓姿：闭合轴为局部 `(-√3/2, 1/2, 0)`，接近轴为
`(√3/4, 3/4, 1/2)`，TCP 位于局部 Z=10 mm。这一抓姿握住六角头的另一对
平面，只用于摆杆，记录为 `fold_support`，不宣称它是同轴卡口抓姿。
直接保持同轴抓姿放倒会使机械臂碰到卫星本体；两种抓姿之间必须真实
松爪、清空、接近、闭合和重新确认接触，不会在握持中直接替换夹持变换。

松开后的倾斜抓姿位于可达边界，回到旋拧抓姿时会边上抬边转腕，再直线
接近；不能继续沿倾斜轴外伸 14 cm。倾斜接近末段的姿态完成距离为 1 cm，
避免在不可达的远处要求已经完成倾斜。完整 20 段参考路径的默认布局预检
检查了 3221 个候选，包括松爪、换抓、摆杆和机构对应姿态。
模型坐标随安装位置和朝向读取，脚本没有写死台面上的世界坐标。

旋拧和摆杆均由机械臂与夹爪原有执行器经接触驱动。控制器只输出六个机械臂
关节和两个夹爪驱动关节的参考值，不写入紧固件或杆的位姿、关节状态、
约束或外加力矩，也不加载独立旋拧演示组件。脚本不因腕部力或力矩超载而
停止；原生动力学的有限状态检查和实际任务验收仍然保留。

该任务使用独立生成的 episode 模型初态：紧固件沿原有 16 mm 导程推进
约 4.791 mm，旋转约 107.8°，关节 `ref` 与刚体参考变换配套设置。
这发生在仿真创建前，其他任务仍保留原始松开初态。原模型铰链的
`[-0.75, 0.15] rad` 行程无法抵达台面的限位卡扣；任务模型扩展为
`[-1.75, 0.15] rad`，仍使用同一底部铰链和原始碰撞几何。
名义放下角为 -1.53 rad，容差 0.025 rad，必须越过卡口唇边后才能释放。
任务模型显式恢复被原杆/底板排除规则一并屏蔽的杆/卡扣接触；保留原始
卡扣几何，以 `solref=0.03 1` 的未标定接触柔度表达约 0.5 mm 的弹性卡口
过盈。底板一块粗凸包造成的虚假挡墙改用原 CAD 材料的精密凸分割，
不切除真实材料。独立物理探针能将杆送过卡口，卸载后仍保持真实卡扣接触；
这不是机械臂任务的端到端验收。不能仅以规划轨迹到达
或模型参考角度作为成功依据。

当前名义速度为平移 5 cm/s、旋转 0.2 rad/s，摆杆角速度同时受夹持点的
线速度和机械臂关节速度约束。旋拧及摆杆参考具有加速度与 jerk 限制。
接触确认后停止继续增加夹爪预载，并平滑停稳机械臂参考，再开始摆杆。
放入卡扣后同样等待规划参考完成减速；实测机构不动不代表指令已停止。
到位后达到实际夹持释放间隙即开始撤离，其余张爪动作与撤离重叠。

验收使用权威物理状态及接触反力：初始和最终必须返回挂钩位置，紧固件
行程处于 4.4–6.5 mm，螺旋耦合残差不超过 0.1 mm。旋紧阶段必须与挂钩
存在至少 1 N 的实际法向反力，且静止连续确认 0.2 s 后才保持参考；首次
碰触不算落座。保存此次达到的行程和
转角。末次松爪后允许无外载的挂钩自然卸载为零反力，但必须保留锁紧
位置与螺旋耦合，且相对已经确认的座合点不得退回超过 0.35 mm 的螺纹
行程或对应转角。没有真实旋紧接触历史、座合后退出过多或杆偏离挂钩，
均不能通过最终验收。初态在无外载时同样允许挂钩自然卸载为
零反力，必须仍匹配任务专用锁紧参考变换、实际行程/转角和静止条件。
旋松必须测得实际退回，不以指令转角代替；放下必须
测得目标铰链角及杆或紧固件与卡扣的实际接触；释放后杆必须继续由卡扣
保持。最终必须完成旋松、放下释放、重抓扶起、旋紧所有阶段，并在末次
松爪后连续稳定 1 s。缺失旋紧阶段真实挂钩力或接触证据时不能判定成功。
旋拧始终保持杆在挂钩的目标角 0，扶起路径完整走到终点后才开始旋紧，
不会把接触顶开的实际杆角持续当作新的目标追随。

先使用平台 Python 从服务端目录运行权威动力学诊断：

```bash
python tools/run_scripted_task.py --task locking_rod_cycle \
  --output /absolute/path/rod-diagnostic --max-sim-seconds 180 --native-geometry
```

诊断轨迹不是带相机的训练 episode。真实训练数据必须通过正式采集入口录制
两路相机，并通过阶段顺序、原生物理状态及最终释放稳定性的验收。
几何可达检查使用独立碰撞探针逐点重放机械臂参考和杆/紧固件的对应标量
关节坐标；这些候选状态只应用于探针，不写入运行中的仿真。
