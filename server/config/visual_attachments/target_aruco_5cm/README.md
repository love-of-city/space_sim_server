# 靶点交接：黑框 5 cm 近距离仿真联调版

版本：2026-10-21-black-5cm-surface-plate。本包中配置、PNG 物理映射和几何使用同一尺寸。
交接说明修订 2：补充新机械臂的爪子中心、相机外参和参数交接模板；靶点几何与原安装板版一致。
用于当前仿真近距离联调；不表示未来双目硬件选型、动态抓取或 17.4 m 视觉接管已验收。

## 固定参数

- 目标父刚体：capture_target；所有坐标均相对目标本体原点，单位米。
- 字典 DICT_4X4_50，ID 0、1、2、3；内部编码 4×4，含黑边共 6×6 模块。
- 黑框边长 0.05 m；白边每侧 0.00833333333 m；整张边长 0.0666666667 m。
- 印刷面 y=0.0578 m，正面朝 +Y；图案向右为 −X，向下为 −Z，不镜像。
- ID0 中心 = (0.1, 0.0578, 0.15) m。
- ID1 中心 = (0.25, 0.0578, 0.15) m。
- ID2 中心 = (0.1, 0.0578, -0.13) m。
- ID3 中心 = (0.25, 0.0578, -0.13) m。
- 四靶整体范围 X=[0.0666666667,0.283333333] m、Z=[-0.163333333,0.183333333] m。
- 黑框角点与排列顺序见 interface.json；测距时采用本包 aruco_rig.json 的真实米制尺寸。

## 导入方法

1. 使用 geometry_metres.json 重建 box，或导入 target_fiducials_metres.obj + 同名 MTL。
2. UE 以厘米为单位时可直接使用 target_fiducials_ue_centimetres.obj（顶点已乘 100）；
   保留 OBJ 原点，作为目标星本体子节点，不要自动居中或再乘 100。
   若目标星导入时另做了坐标轴转换，靶点必须应用相同转换。
3. 使用 PNG 贴平面时，整张 640×640 图片映射到 66.6667×66.6667 mm，
   中间 480×480 黑框才是 50×50 mm。
4. 选择 JSON/OBJ 几何或纹理平面其中一种显示方式，避免重复叠放。
5. PnP 与渲染同时使用此尺寸；不要拿其他边长的旧图像配这个配置。

原四点布局，3 mm 安装板，无支柱。板背面 y=0.05475 m，板正面 y=0.05775 m；另有 0.05 mm 黑白渲染薄膜，PnP 印刷面 y=0.05780 m。X/Z 安装中心保留原值。
这是视觉几何：板跨局部凹槽，白边边缘与少量曲面加强筋相交约 0.11 mm；黑框无遮挡。不是实际结构加工或固定方式验收。
旧版带支柱的 0.972 mm 等误差指标不能直接当成本版已验证精度。
该几何只参与视觉渲染，未配置碰撞与质量。
分离机构参考中心见 interface.json；抓取接触点、爪子中心和新腕部双目外参仍需共同标定。
可见性与误差必须在新机械臂安装后重新验证。

## 更换机械臂时必须重新确定的参数（给接入同学和 AI）

安装靶点可先进行；计算“爪子中心到分离机构中心”的距离时，必须完成下列参数配置。
本包不提供新机械臂的未知数值，请根据新模型/标定填写 `new_arm_calibration.template.json`。
它只是参数交接模板，尚未接入运行程序；`null` 表示待确定，不能直接当成零或单位矩阵用于测距。

| 参数 | 新机械臂需要做什么 |
|---|---|
| 爪子中心坐标系 G | 确认两指之间选定的测量中心，记录所属刚体、局部三维坐标和三轴方向；与机械臂同学约定开合状态。CAD 原点、腕部法兰或旧 `sarm_ee` 不自动等于这个中心。 |
| `gripper_frame.position_in_parent_m` | 填新爪子中心在其父刚体中的 X/Y/Z，单位米。还需记录坐标系朝向 `rotation_parent_from_gripper`。不是只改一个距离或改 site 名称。 |
| `rotation_gripper_from_optical` | 相机光学坐标到新爪子坐标的 3×3 旋转矩阵，光学系为 X 向右、Y 向下、Z 向前。 |
| `camera_in_gripper_m` | 相机光学中心在新爪子坐标系中的 X/Y/Z，单位米。相机在爪子侧面时必须保留侧向偏移。 |
| 相机内参和畸变 | 按实际输出分辨率确定 fx/fy/cx/cy 与畸变参数；不能直接照搬旧腕部相机内参。 |
| `point_target_m` | 当前为分离机构参考中心 (0.1755, 0.073, 0.04207870013) m，在目标星本体系内。只换机械臂时沿用；若目标模型的原点、缩放或机构几何改变，须重新计算。 |

仓库里的 `tools/fiducial_center_metrics.py::load_reference()` 目前只支持旧模型，固定查找
`link6` 下的 `sarm_ee` 与 `sarm_wrist_cam`。换机械臂时，AI 需要根据新模型重写/适配这段读取和坐标变换，
不能把旧模型的 site、相机位置或算出的外参数值直接复制过去。这些源码位于原仓库，不包含在此资源包中。

如果相机与爪子中心刚性固定在同一组件上，两者的相对旋转和平移可标定为常量。
如果相机装在服务星本体、其他活动连杆或活动支架上，两者关系随运动变化，需要按该帧关节状态计算运动学变换；
此时填写 `relative_transform_mode` 为 `kinematics_per_frame`，运行时更新外参，不能始终使用一个固定数值。
固定安装则填写 `constant`。还要明确采用左眼还是右眼光学系；双目需另给两眼内参、右眼相对左眼的旋转/平移与同步配对规则，
仅有“12 cm 基线”不足以完成双目坐标配置。

计算关系（S：目标星本体系，C：所选相机光学系，G：以新爪子中心为原点的坐标系）：

```python
# R_C_S 和 t_C_S 来自图像 PnP；point_target_m 是目标系中的分离机构中心。
p_C = R_C_S @ point_target_m + t_C_S
p_G = rotation_gripper_from_optical @ p_C + camera_in_gripper_m
distance_m = norm(p_G)
```

PnP 输出的 t_C_S 是目标星本体原点的位置；相机到标记的距离、相机到机构中心的距离都不能直接当成爪子到机构中心的距离。
请先核对三轴和米/厘米单位、确认各旋转矩阵方向，再用与图像同帧的仿真坐标计算两个指定中心的真值进行误差验证。
仿真真值仅用于评估，不输入图像 PnP 算法；新机械臂和相机的精度需要重新验证。
本包只有靶点资源和接口参数，没有附带完整 PnP 检测/测距程序。
