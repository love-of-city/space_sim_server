# Fab 地球资产接入与作者示例

资产：Arghanion’s Puzzlebox，`[FREE] Planet Project for Unreal Engine 5`。
商品：https://www.fab.com/listings/fc591129-a147-4684-acbb-38a990e30c3a 。

已领取资产通过 Fab 账户资料库获取。下载包有 34 个 Content 文件，合计 1,060,309,743 字节，全部通过下载 manifest 的 SHA1 校验。
包内有 `Lv_Planet_Project` 示例地图和 `BP_Planet` 组合蓝图；交付类型为资产包，没有 `.uproject` 或作者的工程配置。
原包保存在仓库外，并以不改动 Content 的方式补建独立 `PlanetProjectDemo.uproject`，默认加载作者关卡。
在 Linux UE 5.6.1 上成功加载全部 34 个资产，地图含 7 个 Actor，其中有 3 个行星实例；地图检查为 0 错误、0 警告。
检查脚本读取旧 Actor 别名产生了 3 个 API 弃用警告，没有资产加载错误。

平台通过官方 AssetTools 迁移 7 个包，约 19.5 MiB：地球球体、地表父材质、4 张地球纹理与平台材质实例。
源与目标 SHA256 均记录在本机迁移报告中；旧资产可能被引擎另存为 5.6 格式。
源工程与部署副本只更新地球网格、地表材质两项配置，并校验部署资产与源文件一致。
太阳方向、物理半径、位置、姿态和浮动原点仍由仿真状态驱动；不运行原作者的自转、轨道或重力蓝图。

大气继续使用 UE 5.6 Sky Atmosphere，云继续使用原有球面体积云。
作者透明云层在平台天体独立光照通道下表现异常；尝试的抖动遮罩产生明显颗粒，未作为最终资产保留。
现有体积云也仍有可见颗粒，地表资产替换不等于复现宣传视频或实拍地球。
完整作者示例保留原云、大气、天空与展示逻辑，用于后续视觉对照。

验证：材质参数读回与依赖迁移成功；部署副本 Vulkan SM6 完成全球和地平线的 1024×1024 GPU 采集。
同一仿真状态与曝光下另检查了晨昏线及夜面，渲染日志未报告材质编译或资产加载错误。
夜灯使用原材质昼夜判断，白天固定曝光下很暗，没有将夜灯可见度认定为视觉验收通过。
独立作者工程另用 Xvfb 与 UE RenderOffscreen 生成两个 1920×1080 的地球示例截图，未保存场景改动。
截图脚本的首版因全局资产等待重入 Slate 回调失败，已增加重入保护并改为控制台 HighResShot。
随后将 Slate 回调内的立即退出改为 UE Python 执行器的延迟退出；最终重跑生成两张截图，进程退出码为 0。
作者示例首轮截图偏亮且存在颗粒，不能据此宣称宣传效果复现；其他示例行星的图形效果与蓝图游戏逻辑未完成验收。
本次没有修改 C++；未重复执行与资产导入无关的服务端或动力学测试。

重建脚本与限制见 `space_sim_UE_Adapter/Unreal/BskUnrealRenderer/docs/ARGHANION_EARTH.md`。
资产使用既有 Git LFS 规则，保留 Fab 适用许可；认证文件、签名下载地址、日志、原始完整下载与生成目录均在仓库外。
