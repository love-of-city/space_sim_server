# 全零启动与操作姿态准备

## 使用

1. 新建默认的 **全零启动 → 操作姿态准备** 场景。J1～J6 初始角度为 0°，夹爪保持原开度。
2. 保留默认操作角度 `[0, -67.6, -86.6, 143.2, -85.5, 0]`，或自定义 J2～J5 的操作角度。J1/J6 的准备目标框只读，表示保持原位。
3. 点击 **到达操作姿态** 一次。没有当前页面控制权时先申请，授权后自动开始，不必再次点击。
4. 页面显示准备阶段和进度；只有实测到位后才允许正常末端 IK 遥操作。
5. Esc、中止准备、急停、断线、切换页面/失焦都会撤销准备授权。重新点击发送新的请求；同一目标的中途恢复继续未完成的阶段，不从头重新展开。

已经到位后再次点击只在目标附近确认/微调，不会重新展开 J3。收到首帧新鲜关节遥测前按钮不会放行，避免仿真连接已建立但模型尚未初始化时请求落空。

现在取消原来的第三阶段：不再要求 J1 转到 −30.2°、J6 转到 337.4°。准备时这两轴保持开始准备时的关节参考，全零启动时就是 0°；非零位置重新准备也不会被强行转回零。旧场景或旧页面仍发送原六轴目标时，控制器同样不会恢复第三阶段。此限制只作用于准备流程，正常末端 IK 仍可驱动 J1/J6。

## 正式执行顺序

| 阶段 | J1 | J2 | J3 | J4 | J5 | J6 |
|---|---:|---:|---:|---:|---:|---:|
| 初始 | 0 | 0 | 0 | 0 | 0 | 0 |
| 1 | 保持 | −67.6 | +30 | 143.2 | 保持 | 保持 |
| 2 | 保持 | 保持 | −86.6 | 保持 | −85.5 | 保持 |

- 第 1 阶段先协同运动 J2/J3/J4，J3 的 +30° 是临时让位姿态；最终仍到负角目标。
- 第 2 阶段协同运动 J3/J5；实测稳定后直接进入 ready，开放正常遥操作，没有第三阶段。
- 使用余弦加减速的同步关节参考，不直接写入物理关节位置。
- 每阶段都等实测角度误差 ≤0.8°、所有实测关节速度 ≤0.02 rad/s，连续稳定 ≥0.35 s 再继续。
- 保留现有关节速度和力矩限制。J2/J3/J4/J5 的准备参考速度上限分别为 0.7/0.7/0.9/1.0 rad/s；J1/J6 的准备轨迹参考速度为 0，原物理关节控制器负责保持参考角度，不把它们改为物理锁死关节。
- 保留模型关节限位、8° 跟踪误差中止和每阶段 12 s 到位等待超时；运动前等待稳定停止，不因点击瞬间残余小速度直接拒绝。
- 关节参考与时间推进独立于普通 IK，准备结束后继续原有肘高、腕低、J3 负角软偏好。

**碰撞唯一权威是运行中的原生 MuJoCo/MJScene。** 不创建第二个碰撞场景，不使用 RRT、静态路径校验、目标漂移重规划或独立碰撞否决。旧独立规划及子进程文件已从正式代码移除，排障备份只在忽略的 `run/preparation-repair/before/` 中。

这是一条已针对默认模型、默认操作姿态实测的固定顺序，不是通用避障算法。自定义目标、不同物体位置、其他模型和任意起始构型不能据此保证无碰撞；关节角合法也不等于路径无碰撞。到位成功是实际状态判据，不是“无碰撞证明”。

## 2026-09-21 稳定性修复

两次用户运行日志的直接错误为 `BasiliskError: Encountered NaN acceleration`，分别在仿真时间 72.341667 s 和 37.277083 s。随后启动器清理对应 UE 进程，外观容易误判为 UE 先崩溃。

- 默认固定步长积分在当前 240 Hz 时钟下会出现 J6 数值发散，原生隔离测试可重现。正式运行改用 Basilisk `svIntegratorRKF45`，相对容差 1e-5、绝对容差 1e-6，在每个对外时间步内部控制积分误差。
- 保持 240 Hz 外层动力学/观测时钟、120 Hz 默认 IK、30 Hz 渲染/采样网格；不改变质量、惯量、阻尼、摩擦、PID、力矩限制或碰撞过滤，不裁剪实测状态来掩盖异常。
- 更严格积分需要额外计算；到位时间报告为仿真时间，不保证等于墙钟时间，也不承诺 10 s。
- UE 较早启动失败存在 `InstalledDerivedDataBackendGraph ... no writable nodes`。适配器项目将 Local 文件缓存改为可写，启动脚本预检查写权限并传给 UE 子进程；保留 Zen 快速路径及已有缓存，不用纯内存缓存、也不强制绕开 Zen 导致全量着色器重编译。
- 场景启动器在仿真退出时把具体错误原因传到前端，明确是权威仿真退出后联动停止 UE。

## 代码和测试

- `simulation/arm_preparation.py`：固定阶段、平滑参考、实测到位与中止。
- `simulation/native_integration.py`：原生积分器设置。
- `simulation/teleop_grasp_unreal.py`：原生状态和关节控制器接入。
- `frontend/arm_preparation.js`：一键申请控制权、准备心跳、超时和阶段显示。
- `tests/test_arm_preparation*.py`、`tests/test_native_integration.py`：回归测试。
- `tests/test_arm_preparation_native.py`：设置 `SPACE_SIM_RUN_PREPARATION_NATIVE=1`、`SPACE_SIM_RESET_ADAPTER` 后运行真实控制器测试。
- `run/preparation-repair/`：此前三阶段版本的故障复现及 UE 联调历史。
- `run/preparation-two-stage/`：当前取消 J1/J6 最后旋转的回归和原生测试。

应用更新：刷新前端，停止旧场景并新建全零场景。运行中的旧仿真进程不会热切换控制器。已有 100 Hz IK 的历史配置不符合当前 240 Hz 整数分频时钟，应新建默认 120 Hz 场景。
