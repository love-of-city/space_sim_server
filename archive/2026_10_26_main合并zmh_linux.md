## 冲突处理

- 保留 main 的视觉采集、曝光控制、接触诊断和既有采集接口，同时接入 zmh_linux 的 Linux 部署、批量采集、相机模式、全局机位及插拔件保持力。
- Python 描述符和渲染组件同时保留两侧字段；UE 场景控制器同时保留预览轨道处理、权威视觉采集和相机效果；原生步进器同时保留诊断和轴向摩擦接口。
- Windows 原生编译添加 `NOMINMAX`，避免 windows.h 宏与标准库 min/max 冲突。
- 全局机位的保存标定允许最多 `1e-14` 的绝对浮点误差，兼容不同平台三角函数计算的尾数差异；返回原保存记录。字段、版本、种子、机位和参数仍参与验证，`1e-8` 米的位置改动仍拒绝。
- 三个调用真实 Basilisk 场景加载器的全局机位测试归入已记录的原生验证范围，并实际在原生环境执行；腕部相机测试显式按 UTF-8 读取录制元数据。
