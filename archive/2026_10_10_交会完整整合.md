# 交会接入共同动力学核心与标准场景交接

基线为正式统一仓库 main `5757a13`。将原个人 server/adapter 的配套改动迁入同一分支 `feature/yipuwang-rendezvous-integration`，保留团队模型、协议并沿用已有 PowerShell 部署入口。旧 checkout 与运行资产另行保留；讲稿和汇报页面不属于 Git 交付。

## 问题与实现

旧交会虽能在页面显示，但仍独立使用 MJScene 积分，缺少本轮要求的环境与误差，也没有直接进入标准机械臂场景的完整路径。现在交会与机械臂使用共同 LocalMujocoStepper、Basilisk Earth/Sun、物理端口与 UE 适配器；交会不再执行第二套多体积分或持续回写状态。

- 15 刚体、113 个唯一网格、217 个网格实例和原生三轴轮保持来源可追溯。飞行时臂/指及目标板固定在模型零位，近程交接恢复原有活动自由度。平移质心合力限值 25 N。
- 复用团队阻力公式、Basilisk 指数大气和 Eclipse，加入共转大气阻力、含地影的太阳光压及独立相关的未知加速度。每类环境分力进入原始遥测，不能只修改测量或滤波协方差冒充轨道扰动。
- 双星 2 Hz GNSS 默认每轴 1σ=3 m、0.5 m/s。随机初态、观测与真实扰动力使用分开的种子流；导航持续修正目标估计。参数经白名单、类型、范围与有限值验证后才启动进程，并保存完整 JSON。
- 默认保持 110 m；新工程指标在运行前固定为 100 m 边界、120 s 保持、距离设定 ±5 m、Hill 速度 <0.2 m/s、600 s 捕获后跟踪 <5 m。会议没有定义统计和验收细则，这些是公开的仿真假设，完整范围见交会说明。
- 平台负责自动启动所属 checkout 的 UE，核对 PID、进程创建时间、工程路径及渲染端口归属。新任务清空旧状态但复用渲染器；网页在冷启动结束后重新连接播放器，避免初次等待 streamer 超时后一直黑屏。
- `POST /api/rendezvous/handoff` 只接受已完成、已通过且源模型一致的结果，并与任务/采集启动互斥。标准场景恢复双星、轮、关节、轨道原点、环境随机过程及推进后的 SPICE 历元；观测携带源运行 ID、连续性误差和导航快照。随后使用主页面现有控制、采集、重置、停止接口。
- 长路径 checkout 的 UE DDC 改用每工程的短路径缓存，所有资产准备与渲染入口传递相同命令行参数，不污染父进程环境。沿用团队资产重新编译、导入和准备材质，不复制旧 Saved/Intermediate/DLL。
- 接收端将 JSON 四元数转为 NumPy 数组后调用 Basilisk，正确处理 q 与 −q 两种等价表示；恢复校核覆盖角速度、轮角及轮速。控制验收同时检查目标指令和原生关节反馈。
- 迁入个人分支既有的 SSH 启停隔离、LeRobot 标量序列化修复和多余 CMD 包装器清理。文档统一指向现有 PowerShell 脚本；没有增加新的启动包装器。

## 兼容性与复现

完整云端环境为 Python 3.13、bsk 2.11.1、MuJoCo 3.7.0，两个 editable 包来自同一 checkout。bsk 2.12 的 MuJoCo ABI 与团队当前内置头文件不匹配；不能仅凭 import 成功判断兼容。

远程飞行默认 20 Hz 外层调度、12 内部子步（240 Hz），GNSS 2 Hz、姿态控制 20 Hz。标准机械臂场景维持原有调度与控制。常规场景未提供 handoff 时继续原有行为；历史通用示例和回放保留。

服务端新增 `psutil` 依赖用于所属渲染进程识别。`bsk-render/2`、`bsk-capture/1` 与原控制通道保持不变。交会状态使用只读通道；常用误差选项由现有网页/API 提供。物理与恢复代码 hash、源模型 hash、参数、真值与观测保存在每次结果中。

运行、算法输入输出及任务对应见 [TEAM_RENDEZVOUS](../space_sim_server/docs/TEAM_RENDEZVOUS.md) 与 [个人任务](../space_sim_server/docs/AOC_SEVEN_TASKS.md)。根 CI 部署过滤器覆盖新启动逻辑。基础 CI 排除的原生环境测试已在具备 Basilisk 的实际环境单独执行。
