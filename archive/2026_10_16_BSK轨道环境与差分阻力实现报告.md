## 2. 地球 J2：物理量与实现

地球扁率通过二阶带谐项改变引力加速度，产生轨道面升交点进动等效应。在地固系中，以 `r²=x²+y²+z²`，其附加加速度为：

```text
k = 3 J2 μ R² / (2 r⁵)
a_J2 = k [x(5z²/r²−1), y(5z²/r²−1), z(5z²/r²−3)]
a_total = −μ r_vector/r³ + a_J2
```

生产代码调用 BSK 原生 `SphericalHarmonicsGravityModel`，没有另外维护一套生产用解析 J2 积分器：

```text
maxDeg = 2
C00 = 1
C20_normalized = −J2 / √5
其他非中心球谐项 = 0
```

| 参数 | 本次默认值 | 来源与说明 |
| --- | --- | --- |
| J2 | 0.001082616 | 固定为 BSK 2.11.1 `astroConstants.J2_EARTH`；随场景保存，不随依赖升级悄然改变 |
| μ | 3.98600436 × 10¹⁴ m³/s² | 当前 BSK `createEarth()`，实际值写入遥测 |
| R | 6378136.6 m | 当前 BSK 地球赤道参考半径，实际值写入遥测 |
| 地固系 | IAU_EARTH | SPICE 提供姿态 |
| 惯性系 | J2000 | 保留已有坐标系约定 |

该 J2 是明确来源的常数近似，并非本次重新标定的 EGM 系数。更换系数时应同步填写准确的 `coefficient_source`；来源文字用于追溯，软件不能验证文献真实性。

参考点 O 和实际物体的场求值共享同一个地球引力模型。对第 i 个物体：

```text
F_i = m_i Σ_sources {g_source(r_O + x_i, t) − g_source(r_O, t)}
sources = Earth(point mass + J2), Sun(point mass)
```

球谐模型已经包含中心引力，不能再叠加一次地球点质量。局部坐标轴平行 J2000，只随 O 平移，不人为加入 LVLH 科氏或离心力。参考点 O 只进行引力传播；实际刚体的阻力不能作用到 O，否则会错误改变所有物体共用的参考运动。

本次仍以各刚体质心取样引力，未新增单个有限刚体自身的重力梯度力矩。多个刚体质心处的力仍可自然形成多体效应。

## 3. 大气阻力：密度、共转速度与逐物体差异

### 3.1 密度

采用 BSK 指数大气模型，但配置输入改为轨道高度附近的锚点：

```text
ρ(h) = ρ_ref exp[−(h−h_ref)/H]
BSK.baseDensity = ρ_ref exp(h_ref/H)
BSK.planetRadius = Earth.radEquator
```

`h` 是球形径向高度，不是椭球大地高。模型不包含空间天气、昼夜变化或非共转风场，不能将其当作 MSIS/Harris–Priester 的等价替代。

旧可选入口未赋予有效的 `baseDensity` 和 `planetRadius`；本机 BSK 2.11.1 默认两者为零。仅打开旧开关不能证明原场景已具有有效阻力。本次要求提供密度、标高和逐物体弹道参数后才能启用。

### 3.2 相对大气速度

令 `C` 为 J2000 到地固系的方向余弦矩阵，`Cdot` 为其时间导数：

```text
v_atm,N = v_Earth,N − Cᵀ Cdot (r_body,N − r_Earth,N)
v_rel,N = v_body_COM,N − v_atm,N
F_drag,N = −½ ρ Cd A |v_rel,N| v_rel,N
```

配置化场景使用 SPICE 的实际姿态与导数，包含地球平移和共转运动；没有把 J2000 固定 z 轴直接当成当日地球自转轴。运行时检查有限星历、正交旋转矩阵和有效密度。

### 3.3 分别作用到本体和目标

每个配置 body 独立创建密度取样器与外力发布器，经既有 `PhysicsPorts.add_body_wrench` 作用到该刚体质心。质量继续取自 MJCF，故同样的气动力对不同质量自然产生不同加速度。

配置化入口的压心偏置为零，不额外施加显式气动力矩。多体中各质心的实际作用点仍可能影响整体姿态。`A` 为固定有效迎风面积，本次没有根据姿态、遮挡或面板几何实时计算投影面积。

合成示例仅用于接口和敏感性验证：

| 参数 | 示例值 |
| --- | --- |
| 参考高度 | 500000 m |
| 参考密度 | 1 × 10⁻¹² kg/m³ |
| 标高 H | 60000 m |
| cubesat_bus | A=0.06 m²，Cd=2.2 |
| capture_target | A=0.12 m²，Cd=2.2 |

示例只向 bus 分配面积，未包含面板。不得为每个刚性连接零件重复分配整星面积，也不得直接套用参考库 ISS/Dragon 的参数。

### 3.4 参数约束

- 密度、标高、面积和 Cd 必须为正有限数，参考高度必须非负。
- 禁止重复 body、未知字段、空来源和指数上溢；未知 body 在装配阶段报错。
- 必须记录 `density_source` 和每个 body 的 `parameter_source`。
- J2/configured drag 仅支持当前 `local + bsk` 路径；不支持的后端组合显式报错。
- `--atmospheric-drag` 不再隐式采用缺少标定的默认值；它要求配置中已存在阻力参数。

## 5. 验证结果

验证环境：Windows、Python 3.13.14、Basilisk 2.11.1、MuJoCo 3.7.0、NumPy 2.3.5。产物位于本地 `reports/bsk-orbital-implementation/`；运行日志和生成数据不作为源码提交。

### 5.1 轨道数学验收

原生 BSK 独立参考传播：500 km、51.6°、步长 1 s、记录时长 11350 s，约两圈。为对照解析模型，该试验固定地球极轴并关闭太阳；生产场景仍用 SPICE 与太阳。

| 检验 | 结果 |
| --- | --- |
| 200 个静态位置：BSK J2 与独立解析公式最大加速度差 | 3.57 × 10⁻¹⁵ m/s² |
| 点质量相对能量漂移最大值 | 5.77 × 10⁻¹⁵ |
| 点质量角动量模长相对漂移最大值 | 3.11 × 10⁻¹⁵ |
| J2 正确总势能对应的相对能量漂移最大值 | 1.62 × 10⁻¹⁴ |
| J2 极轴角动量相对漂移最大值 | 7.33 × 10⁻¹⁵ |
| J2 升交点一阶理论进动率 | −9.59996 × 10⁻⁷ rad/s |
| J2 拟合进动率 | −9.62407 × 10⁻⁷ rad/s |
| 进动率相对一阶理论偏差 | 0.251%（验收阈值 2%） |

J2 下两体能量和角动量模长本来就不是守恒量，工具单独输出它们作诊断，没有错误地要求恒定。上述接近浮点精度的守恒结果只描述该独立 BSK 算例，不代表 MuJoCo 多体系统长时精度，也不等于与真实轨道误差。

证据：`orbit-acceptance.json`。

### 5.2 阻力与耦合验收

两自由刚体测试使用 160 kg / 10 kg 的测试质量、面积 0.06 / 0.12 m²，以及放大的合成密度 10⁻⁹ kg/m³，以便在 0.2 s 内可靠分辨速度变化。验证非零密度、阻力逆气流方向、力之比约 2、减速度之比约 32、无显式压心力矩。另验证倾斜自转轴与天体平移情况下的气流速度、多个外力来源叠加，以及 J2/太阳差分引力的步间保持对照。

完整 SARM 模型使用独立离线 profiler，读取已有场景初值，不改变原文件或运行进程：

| 场景 | 模拟时长 | 物理步数 / 帧数 | 结果 |
| --- | --- | --- | --- |
| J2 + 太阳，阻力关 | 10 s | 2400 / 301 | 地球原生球谐模型、太阳点质量、15 个物体正常求值 |
| J2 + 太阳 + 合成逐物体阻力 | 10 s | 2400 / 301 | 本体和目标均有非零密度与气动力 |
| 地球点质量 + 太阳，阻力关 | 2 s | 480 / 61 | 回退路径运行正常；诊断实例保存 point_mass 覆盖配置 |

阻力场景末帧本体密度约 1.0000144 × 10⁻¹² kg/m³，目标约 1.0000304 × 10⁻¹² kg/m³；力大小约 3.53 × 10⁻⁶ N / 7.06 × 10⁻⁶ N，符合该合成面积设定。验证含真实 SPICE、MuJoCo 模型和会话装配，不含 UE 渲染、网络或 LeRobot 录制。

证据：`j2-runtime.*`、`drag-runtime.*`、`point-mass-runtime.*`。前两个会话的 `.scene.json` 生成时尚未加入 profiler 保存覆盖配置的改动，应以启动日志和 observation 中的有效配置为准；最终工具已补齐保存行为，并通过点质量会话验证。

## 6. 与参考仓库的关系

参考固定提交 [OWM 78696acc](https://github.com/sisl/outofthisworldmodel-envs/tree/78696accd8eebdc0319e616dcc1e72308cd3bb48) 的 `iss_numerical/dynamics.py` 与 `common/zonal_gravity.py`，借鉴摄动分层组织、逐物体弹道参数和轨道验证方法。用户最初提供的 `datasets/lerobot_writer.py` 是数据写入器，不承担轨道动力学。

本次生产代码使用 BSK 原生场模型，没有复制 OWM 的 JAX 动力学、RK4 推进器或引入 JAX/astrojax 依赖。此前比较中，单独抽取参考仓库公式进行 NumPy 静态场对照，在统一常数后 1010 个样本最大差约 5.5 × 10⁻¹⁵ m/s²；这只是公式对照，不是运行完整 OWM 平台或跨平台长轨迹验证。

OWM 的默认 ISS 环境含更高阶带谐、日月引力及 Harris–Priester 大气，不能据此认为所有默认项都适用于当前短时近距离抓取任务。本次不加入月球、J4/J6 或太阳光压。未来转向长时高精度轨道任务时，应根据时长、轨道高度和误差预算再决定是否加入太阳/月球摄动及更完整密度模型。

## 7. 使用与后续优先项

完整操作、物理公式与配置说明见 [轨道物理配置文档](../space_sim_server/docs/ORBITAL_PHYSICS_CONFIGURATION.md)。配置样例位于 [config/orbital](../space_sim_server/config/orbital)。

从服务端目录可复现独立验收：

```powershell
..\.venv\Scripts\python.exe tools/verify_orbital_physics.py --output ..\reports\orbit-acceptance.json
..\.venv\Scripts\python.exe tools/profile_simulation_runtime.py --adapter-root ..\space_sim_UE_Adapter --scene-instance run/scenes/<实例>.json --orbital-config config/orbital/j2.json --duration 10 --motion hold --output ..\reports\<新的结果名>.json
```

后续最有价值的工作是标定本体/目标迎风面积、Cd 与任务历元密度，确认面积是否覆盖面板，再用真实参数启用阻力。需要更高精度时，再进行长时多体误差评估、按姿态计算面积或接入更完整的大气模型；这些能力没有在本次实现中隐式启用。
