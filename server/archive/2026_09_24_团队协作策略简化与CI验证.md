# 团队协作策略简化与 CI 合并验证

日期：2026-09-24

## 背景与变更

准备后续合仓，删除 docs/COMPATIBILITY.md、docs/compatibility.json 和旧仓库设置说明，移除对应 README 链接，停止维护双仓固定提交配套表。保留现有基础 CI、Basilisk 功能检查及协议测试。

统一 CONTRIBUTING.md 和 PR 模板：提交说明原因，大型变更存入 archive/ 日期命名文档；保留 merge、squash、rebase 三种仓库配置，本次明确采用 squash。配置文件不代表远程设置已经生效。

服务端 CI 仍需独立适配器，当前直接检出其 main，删除固定 SHA 读取步骤。历史诊断记录整理到 archive，相关文档链接同步调整。治理分支合入最新 main，保留主线新增场景功能与信令监听就绪修复。

## 验证与边界

通过本次 PR 的 GitHub Actions 验证 server-python、server-web，仅在最终提交的检查通过后 squash 合并，并检查 main 的 push 工作流。实际执行结果与运行链接记录在 PR 验证证据中；此文档不预先宣称通过。

未执行 UE 构建、GPU/WebRTC 和真实 Basilisk 全链路验收；基础 CI 不代表这些功能验收通过。本次不新增本机绝对路径、秘密或二进制资产。

## 风险与回退

适配器 main 可独立变化，服务端 CI 不再固定其版本；合仓前仍需要两个同级检出目录。如需回退，通过新 PR revert 本次 squash 提交，不重置或强推 main。
