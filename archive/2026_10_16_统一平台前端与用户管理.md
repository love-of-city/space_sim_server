# 统一平台前端与用户管理

日期：2026-10-16。分支：`feature/unified-platform-ui`，基于本次同步的 `origin/main`。

## 问题与改动

自动采集与数据查看原先使用独立页面和不同风格，入口与遥操作控制混在一起。现统一为左侧导航、顶部状态栏和主内容区，沿用平台浅灰背景、白色面板与蓝色强调。仿真工作台、自动采集、数据集、用户管理在同一应用内切换。

- 工作台保留视频、场景控制、关节与六维力遥测。离开时先清除操作输入、发送停止指令，再释放控制连接和视频资源；返回后重新连接。
- 自动采集区分当前与历史批次；新建表单分为基本设置和高级规格，采样规格从后端读取。批次及成功记录可直接进入对应数据列表/详情。
- 数据集采用列表到详情的结构，提供文本、来源、结果、任务、日期、批次筛选。详情保留双路视频、时间轴、逐帧/倍速、图表缩放和 CSV 导出；曲线按关节与夹爪、六维力、末端状态、任务状态分组。
- 用户管理接入真实 API，支持账号新增、显示名称/角色编辑、启用/停用、重置其他账号密码和最近登录时间。当前管理员不能停用自己或移除自身管理员权限。
- 停用、变更角色和重置密码会撤销该用户的会话；已有数据保留，后台批次独立管理。操作员沿用仅访问本人数据/批次的权限。

## 实现与兼容

使用原生 ES modules 和现有 Vite，无新增框架或依赖。`frontend/platform_shell.js` 管理导航，`ui.js` 提供安全文本渲染和公共表单，`pages/` 按页面划分模板与生命周期。页面 ID 自动加前缀，避免多个模块共存时冲突。

四个页面地址 `/`、`/collection`、`/datasets`、`/users` 返回同一构建。保留 episode/batch 深链接及正常导航中的 access_key。移除原 `frontend/public/collection` 和 `frontend/public/datasets` 独立实现。退出登录会清理各页数据、媒体和表单。

AuthStore 启动时增量添加 `display_name` 和 `last_login_at_ns`，保留已有用户 ID、密码哈希和数据归属。原操作员 API 继续可用，新增通用用户管理 API。

动力学、UE、自动采集器及数据写入链路不在本次修改范围。50 Hz 主数据、200 Hz 独立六维力、双相机 1024×1024 与七维 state/action 格式保持兼容。

## 使用与验证边界

当前代码已构建到 `space_sim_server/frontend/dist`。原平台后端需要按原启动方式重启，然后刷新网页，以加载统一路由与新增用户接口。认证库将在新后端启动时自动迁移。无需重新编译 UE。

本轮完成页面与接口集成验收，未重新执行完整 UE 录制或并发性能测试。实际采集任务沿用已有实现。详细使用和扩展方式见 `space_sim_server/docs/PLATFORM_AUTOMATED_COLLECTION.md`。
