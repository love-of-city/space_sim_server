# D02：非合作目标的测距与多普勒轨道估计

`d02-noncooperative-radar-estimation-v1` 对应 D02、P1、V0、非合作目标 N。两个原团队航天器在真实原生场景中自由传播，方法没有推力或飞轮控制权。目标不提供 GNSS、通信、姿态、控制协作或标志物图像；方法输出目标在地心 J2000 中的质心位置与惯性速度，不是追踪星减目标星的相对状态。

目标初始近圆轨道高度为 500 km ±1 km、倾角 51.6° ±0.2°、真近点角 180° ±2°，独立均匀抽样；公有上下文只提供分布。追踪星相对目标 TNR 初位为 `(-500, 50, 20) m`、初速度 `(0, 0.05, 0) m/s`，各轴分别在 ±5 m、±0.02 m/s 内抽样。没有向方法提供本回合实现的目标初始状态。

每 0.5 s 提供自身 GNSS 质心解和姿态测量，以及主动测距、机体系单位视线、距离变化率。独立高斯噪声标准差为：自身位置 0.2 m、速度 0.002 m/s、姿态小转角各轴 0.00002 rad，距离 0.05 m、视线小转角各轴 0.0001 rad、距离变化率 0.002 m/s。姿态不由 GNSS 冒充。传感器根据两颗航天器当时的真实状态与追踪星物理姿态产生测量，再加入噪声；输出中无目标状态或环境滤波后验。

这是声明的理想化全向主动雷达观测模型：50–2000 m 工作范围、零投递时延、目标质心等效散射点。尚无射频功率、天线指向、雷达散射截面、结构散射点漂移、多径、探测概率或遮挡模型。因此该配置评测测量条件下的非合作轨道估计，不声称已模拟真实雷达硬件或目标搜索。非合作不意味着无法通过主动探测观测目标。

180 s 完整窗口使用 400 Hz 原生积分、50 Hz 权威物理证据、2 Hz 测量与估计输出；保留地球点质量、太阳引力、阻力、太阳光压和随机扰动。独立评分检查全部 360 个目标状态估计与 361 次实际传感器投递。位置 RMSE ≤1 m、速度 RMSE ≤0.08 m/s，峰值分别 ≤3 m、≤1.5 m/s；初期横向速度尚未收敛也计入全时窗。末态准确不能抹去早期误差。重复、缺失、错序、跨回合或与物理时刻不一致的投递/估计不能通过。

双星 COM 间距全程 100–1000 m，旋转 TNR 相对速度不超过 2 m/s；任何大于数值容差的实际推力、初始化后状态回写均否决。原生模块只接收零力动作，估计输出不会更改物理状态。评分记录实测距离、惯性视线及距离变化率相对物理真值的 RMSE，便于区分测量噪声与估计误差。没有有效燃料或电能模型，相关字段保持 `null`。

`radar-orbit-estimator-v1` 使用公开自身状态、测距和姿态/视线初始化目标位置；初速度仅加入观测到的径向分量，横向分量采用宽协方差先验。随后用点质量轨道传播和扩展卡尔曼更新，从连续视线恢复横向速度，不伪造三维目标速度观测。`frozen-radar-estimate-v1` 保持最初估计；`zero-radar-estimate-v1` 始终输出零。两者用于验证全时窗与非空估计判据。外部 JSONL 方法、批次恢复、数据集和原工作台复用统一接口。

```text
python tools/autonomy_benchmark.py schema --kind radar-navigation
python tools/autonomy_benchmark.py run d02-noncooperative-radar-estimation-v1 --seed 1 --output run/d02-train-1

python tools/autonomy_benchmark.py batch d02-noncooperative-radar-estimation-v1 --split test --output run/d02-test
```

训练/验证/测试划分为 1–3 / 101–103 / 201–210。P1 验收预先固定 201–203，其余七个不计入本轮矩阵。先完成原生双星/无目标链路/复位检查（种子 3）、原 S14/D01 物理回归、训练 1/2，再冻结源码运行三个测试种子、两个负对照、独立进程、恢复、复算、数据集、CLI 取消及网页流程。当前新增实现仍待云端检查与原生验收，注册不等于通过。
