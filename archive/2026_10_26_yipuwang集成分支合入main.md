## 冲突处理与主线保留

本次存在两个合并基点：`ee51de8` 与 `9fda0d8`。交叉历史使部分相同功能在两边的位置和提交关系不同。

- 相机描述保留 main 的字段顺序与校验，并合入相对视图定义。
- UE 场景控制器同时保留 Linux 离线天空光处理与交会相对视图查询。
- 网页同时保留“继承交会终态”显示和全局相机随机初始化信息。
- 原生步进器保留 main 的接触、物体速度与摩擦接口；采用受保护的 `NOMINMAX` 定义。
- Python 步进器的接触查询方法保留单一定义；渲染组件保留腕部相机模式及全局相机位姿设置。
- 插拔件保持力组件保留 main 的安装位置，同时接入交会交接与陀螺组件。
- CI 排除清单合并双方条目，保留纯 Python 覆盖与原生环境验收边界。
- 恢复递归合并自动删除的 9 份 main 归档文档；相对 `ee51de8` 仅在 main 变更的 48 个文件均保留原内容。

相对目标 main，模型、网格和 UE 二进制资产没有变更。部署入口仍由根 CI 的现有部署路径过滤器覆盖。
