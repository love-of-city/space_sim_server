# 随机布局接入自动采集

## 改动

- 新增 `collection-layout-pool/1`，至少两个不同独立布局，绑定模型、清单、原生验收报告、UE catalog 哈希及全部生成视觉资产。
- `prepare_collection_layout_pool.py` 串行生成位置/朝向布局、检查原生及导出几何、导入新 UE 资产命名空间，再发布完整池；可注册已有验收布局。导入对同一项目加锁，worker 仅只读使用。
- 脚本批采集、抽屉/插头包装入口支持 `--layout-pool`；并行配置新增 `layout_pool`，协调器先保存成员快照，再传给所有 worker。
- 网页 API 新增 `layout_randomization`，后端通过 `SPACE_SIM_COLLECTION_LAYOUT_POOL` 配置池，网页显示可用数量并提供开关。未配置有效池时明确拒绝启用，不会退回固定模型。
- 每次尝试使用独立命名 RNG 选择布局；每次编译对应原生模型预检，将同一模型/catalog 传给动力学与 UE 采集。episode 保存选择种子、布局生成种子、XY、yaw、哈希和完整清单，验收额外检查记录与选择一致。
- 维持机构初始状态及 20 N 插拔阻力。原模型、公网部署均未修改。修正网页采集环境检查中硬编码 Windows UE 路径，复用现有跨平台解析器。
- UE 离线采集模式直接跳过屏幕 HUD 绘制；相机采集仍走原有权威通道。改动只同步到本次隔离 runtime，并编译通过。原引擎 Build.sh 因尝试 chmod 只读 dotnet 失败，改为直接调用现有 dotnet/UnrealBuildTool，未修改引擎权限。
