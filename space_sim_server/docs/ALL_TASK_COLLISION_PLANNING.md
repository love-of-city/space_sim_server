# 自动采集：布局避障、接触物理与计时

六项生产采集任务（抽屉、三类插头、航空螺丝、杆状螺丝）通过 `collection/run_scripted_task.py` 自动启用原生几何检查。单条录制、批量采集和网页启动的批量采集均复用此入口，无需额外开关。原始控制器仍以真实关节、接触和物体位置判定成功；没有焊接物体、写入运行中的物体位姿或恢复插头/螺纹任务的超载停止。

## 路径规则

- 六任务的接近（包括杆状机构换抓接近）先生成 TCP 起点到抓取点的直线，途中同步调整姿态和开爪。对准与开爪平滑完成，不引入轴向预抓取点或中途停顿。短距离、横向接近也直接尝试，不要求起点高于抓取轴。
- 以当前布局和测得的原生状态检查全臂、夹爪及持物。接近直线通过时记录 `route=straight`；只有碰撞、间隙或 IK 可达性检查未通过，才搜索绕行。其他搬运及撤离仍保留其已检查的原轨迹。
- 绕行采用确定性 RRT-Connect、捷径化及 C2 平滑，再次检查实际执行曲线。空手接近直接到目标抓取位姿，不强制轴向末段；持物搬运保留装配所需的轴向通道。目标朝向与关节范围保留；不保证全局最短，搜索预算耗尽也不等同于物理不可达。
- 已抓物体随夹爪扫掠，只豁免指定手指与所抓物体的预期接触；腕部、其他臂段和邻近操作件仍参与检查。
- 插头拔出/插入、抽屉导轨是受约束运动：进入阶段时以测得状态做名义操作通道检查，不允许搜索把它们横向带出导轨/孔壁。螺纹任务还预检旋拧、折放等机械路径。堵死的通道被拒绝，不能声称任意随机布局都能成功。
- 松爪撤离检查包含继续开爪的过程；搜索得到的 7 维轨迹用同一个时间轴控制机械臂和开度。搜索约束开度单调，平滑后的开爪曲线再次参与碰撞检查，避免绕行中反复开合。
- 定时接近由已检查轨迹独占控制。三个插头不再在接近指令上叠加第二路漂移跟踪；残余零件漂移在物理抓取阶段跟随，仍要求真实接触和卡扣对齐。
- 圆柱插头松爪前继续插入反馈，要求法兰间隙小于 0.1 mm（更严格的已有配置仍生效）。卸载完成后，在持续开爪过程中保持释放开始时测得的腕部位置和朝向，加入测得速度阻尼，并把累计关节参考偏移连续回算到入口关节锚点，避免阻塞时积累预载、脱离后回弹。最后一个手指脱离不会切断反馈。目标不随已松动的零件漂移，速度与关节指令超前量沿用接触控制的限制。最终静止验收标准不变；搜索撤离结束后保持最终开度，不重放旧松爪计时。
- 圆柱保留远端较慢的接触区开爪及接近全开的撤离门槛；满足该门槛后，同时检查当前实测和指令位姿的 2 mm 间隙。未通过时由当前布局计算所需开度，继续既有开爪动作并复查新状态，几何检查不增加固定等待，远端的最小开度门槛继续生效。直接抬升模板失败后，绕行搜索复用这些抬升终点及同一总预算，不再误退回可能位于邻件内的低位终点。

查询使用独立 native 模型，不膨胀真实碰撞体、不修改生产状态。空程间隙为 2 mm；最终检查按关节样条导数界限控制有限采样间距，样条中各维度相邻采样变化至多 0.006 rad。7 维绕行样条包含夹爪开度；直线候选及部分撤离使用独立开爪函数，在同一组至少 301 个姿态采样点检查实际夹爪，但该独立开度不具有上述 0.006 rad 间距保证。这些检查不是精确连续碰撞证明。接触反馈、自由基座漂移和观测噪声可能使实测轨迹偏离名义路径，因此批量采集仍必须执行完整回合验收。

失败报告中的 `first_collision` 是首个未通过的接触对，不是全模型最小间距；其中一个正间距不足的接触不能证明同一姿态不存在其他穿入。

## 速度

插头保持现有拔插 0.025 m/s、搬运 0.05 m/s；其余阶段沿用各任务速度配置。直线按真实直线距离定时，保留速度、加速度和加加速度限制；不再按旧曲线的轴向投影扩大减速段。绕行不降低配置上限，但路程变长或曲率增加仍可能增加耗时；不能保证绕路与直线同样快。实际采集效率按完整回合衡量，不能只比较一段空程的速度。

接近策略更新后的任务版本为 `drawer-cycle/6-straight-approach`、`plug-insert/14-straight-approach-gentle-release`（三类插头）、`aviation-bolt/4-straight-approach` 和 `locking-rod-cycle/3-straight-approach`。旧录制的阶段解析保持兼容，新的采集记录可区分两种策略。

## 当前验证范围与已知问题

合并远端前的本地快照 `77f1367` 中，默认布局六任务均通过原生完整回合；所测一组位置和朝向随机化的 J2 布局中，航空插头、导向插头及两项螺丝任务通过。抽屉松爪后残余抬高约 1.14 mm，卡扣被安装板顶住，复位误差超限而释放超时；直线修改前的同布局对照也复现该故障。圆柱插头完成插入和撤离后残余自转约 0.03835 rad/s，超过 0.03 rad/s 静止标准，最终验收超时。这些历史失败与原验收阈值保留，未自动收录为成功数据。推送前合并了远端圆柱慢开爪与孔内轴向旋转阻尼；合并后的实测结果单独记录，不能用上述合并前结论代替。完整证据与版本边界见 [六任务直线优先接近归档](../../archive/2026_10_28_六任务直线优先接近.md)。

## 孔壁横向作用

20 N 为额外的轴向干摩擦保持力，并非全部接触力。实际 MJCF 孔壁接触使用 `condim=4`、滑动摩擦系数 1.2；MuJoCo 自动在接触平面的两个切向施加摩擦，另有法向反力。已有横向弹性导向力不是摩擦，不应混淆。

新增 `LocalMujocoStepper.contact_material_snapshot()` 读取实际混合后的接触维数和五个摩擦系数，可与 `contact_force_snapshot()` 对应，均不推进或修改动力学。`tools/diagnostics/validate_plug_retention.py --case lateral_initial --case lateral_target --output ...` 在生产轨道/自由基座模型中施加插座局部 ±X、±Y 的 12 N 载荷，报告法向反力、两切向力和横向位移。该测试还包含独立的 3 mm 紧配合诊断；不通过这一项不能解释为没有摩擦。它不代替实物摩擦、孔径和刚度标定。本次没有重复叠加世界 XY 固定阻力。

## 墙钟计时

单录 `summary.json` 和批采集条目新增：

- `startup_to_recording_end_wall_seconds`：录制脚本启动至收到任务终止、开始停止录制的实际时间，含模型加载、预检和 UE 启动。
- `startup_to_finalized_wall_seconds`：启动至双相机视频封装、队列排空完成。
- `recording_ended_at_ns`、`recording_finalized_at_ns`：相应 UTC Unix 纳秒时间戳。

已有 `recording_wall_seconds` 只表示录制阶段；`recorded_sim_seconds` 是视频/仿真时长，不能用来替代墙钟耗时。`end_to_end_wall_seconds` 还包括进程收尾。失败记录保留失败原因，不能作为成功轨迹采入。

所有六项任务现在均有几何预检。首次权威状态等待默认为 600 秒，可用 `--startup-timeout-seconds` 显式设置；这只是启动截止时间，不会插入固定等待，也不改变仿真速率。

合并远端 `76b64f0` 后的独立复测：391 项相关测试通过，默认抽屉成功，随机抽屉仍卡扣复位超时，随机圆柱插头成功（75 仿真秒）。旧默认圆柱模型因缺少独立孔位颜色绑定，在启动前被保留的颜色指令检查拒绝；采集时须使用符合该要求的独立布局。上述为原生无渲染验证，不代表合并版本已完成六任务 UE 视频验收，详见归档记录。
