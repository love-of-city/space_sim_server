## 任务顺序与调姿

计划衔接顺序：GNSS远距交会 → 约110 m交接并继承导航 → 50 m停泊 → 17.4 m停稳并做目标星预对准 → 检查原相机实际视觉及原保护规则 → 满足条件后继续至5.5 m联合检查 → 最终作业驻留 → 机械臂近距抓取。

其中视觉接入是尚未闭合的环节。17.4 m是预对准候选位置，不是原相机已能识别的距离；没有视觉时仍受正式12 m保护约束，不能据纯GNSS独立诊断直接放行。

GNSS从交会任务开始工作，远近交接继承其后验与传输状态。此前12.5 m初始化只是独立诊断起点，没有继承远距状态；该诊断前20 s在起点保持，不能当作正式任务必须在12.5 m重新初始化。

预对准利用GNSS相对位置、合作目标星姿态/角速度、服务星姿态和抓取臂编码器，计算靶标面朝向相机的期望姿态。PD控制输出范数不超过0.02 N·m的等效力矩，由动力学积分转动。姿态误差<1°、角速度误差<0.001 rad/s并连续5 s才报告对准。17.4 m处90°和180°无图像调姿已独立验证；没有用到新增长焦图像。目标执行器与合作遥测仍属仿真假设，尚未接入网页默认自动触发。

## 靶点与PnP

[靶点信息：可直接放入整体方案第7节](TARGET_MARKER_REPORT_20261029.md)列出23块靶标的字典、尺寸、编号、布置、识别规则及完整坐标附录。

实际近距算法为OpenCV PnP候选＋左右联合重投影优化，输入为原始图像、标定和已知靶标角点，不输入仿真真值。全图检测保留原小邻域并扩至103×103；每眼至少一块完整靶标，最短边≥12 px，并通过正深度、重投影和歧义筛选；无需两眼识别相同ID。PoseLib为调研路线，不能写成当前采用的求解器。

对选定目标参考点c_T，计算`c_C=R c_T+t`，再由相机到夹爪外参换算`c_G`；不能直接把t当成抓取距离。导航结合图像同历元服务星姿态和关节FK，将位置转换到两星本体原点相对位置，与GNSS顺序更新EKF。当前EKF融合位置，图像姿态输出尚未接入完整姿态滤波。模型与参考点版本须一致。
