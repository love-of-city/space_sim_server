# 抽屉速度曲线平滑与接触验证

日期：2026-10-18。分支 feature/drawer-speed-profile。在上一版 drawer-cycle/2 提速基础上，实现 drawer-cycle/3；代码未提交或推送。

## 问题与目标

用户发现提速后的关节角速度出现较多折角。上一版把整体五次时间曲线换成了分段恒加速度的路径计时，并通过直线连接离散 IK 关节位置；路径进度加速度存在切换，关节路径斜率在节点间也不连续。

本次保留主体 0.1 m/s 目标、接近把手末段 0.025 m/s、归位末段 0.012 m/s、旋转 0.2 rad/s 和机械臂参考限速 0.35 rad/s，改善正常运行中的速度与加速度连续性。测量值、数据集和可视化均不做平滑滤波。

## 实现

- 新增 simulation/scripted_tasks/joint_path.py：仅依赖 NumPy 的 not-a-knot 三次样条，保持原 IK 节点，路径位置、一阶和二阶导数连续。以解析极值检查点间关节限位，并计算一至三阶导数界。
- 重写 motion_timing.py：五次速度过渡连接起步、巡航、减速区和停止；边界速度/加速度连续，计入关节路径曲率，通过整体时间缩放满足参考速度、加速度、分段跃度限制。三次样条的三阶导数可以在节点跳变，但保持有界；不声称跃度本身处处连续。
- drawer_lift.py 提供平滑路径与夹爪更新扩展点，旧 lift/插头保持原有行为。drawer_cycle.py 接入新轨迹，并为夹爪开合加入平滑起停；进入下一阶段前还要完成夹爪参考动作。
- 正常连续执行的加速度/跃度配置：平移 0.2 m/s² / 0.8 m/s³；旋转 0.4 rad/s² / 1.6 rad/s³；机械臂关节 0.7 rad/s² / 8 rad/s³；夹爪 0.4 rad/s² / 1.6 rad/s³。
- 夹爪最终默认仍为最高 0.2 rad/s。支持闭合末段限速参数，但默认末段上限也为 0.2；低速闭合试验没有稳定降低碰撞瞬时峰值，因此不作为默认方案。
- NativePoseProbe 对实际平滑接近路径增加原 IK 间隔的中点采样。本次三个初态各检查 484 个位姿，均通过；这仍是离散预检查，不代表连续碰撞完备证明。
- 保留 80 N / 8 Nm 持续 0.1 秒的腕部保护、0.06 rad 跟踪暂停、双侧手指接触、完整抽出、归位、松爪、撤离与稳定成功判据。没有改模型、控制增益、物理状态、接触约束或验收阈值。

正常参考的平滑界不等于实测运动的界：接触、机械耦合和保护停机仍可能产生瞬时尖峰。短行程可能达不到 0.1 m/s；本次抽出实际峰值约 0.0903 m/s，放回约 0.0785 m/s，空程仍达到约 0.1 m/s。极短归位继续保留至少 1 秒运动时间。

## 最终改善与限制

以下均来自 200 Hz 原始 trace，通过 5 ms 时间差分计算；主动运动阶段指 above_drawer、align、descend、lift、return、retract，统计保留这些阶段的实际瞬态，不包含 grip/release 阶段。

| 指标 | 上一版 | 最终版 |
|---|---:|---:|
| 关节参考跃度峰值 rad/s³ | 99.018 | 2.643 |
| 实际角速度差分跃度 P99 rad/s³ | 20.506 | 5.013 |
| 实际角速度差分跃度最大值 rad/s³ | 1930.722 | 1490.633 |
| 抓紧阶段实际机械臂角速度峰值 °/s | 5.577 | 5.332 |
| 松爪阶段实际机械臂角速度峰值 °/s | 3.062 | 3.945 |

参考跃度峰值下降 97.33%；任务仿真时间增加 5.845 秒（12.01%），相比最初 128.335 秒仍缩短 57.53%。P99 是所有对应时间点/关节的绝对值分位数。差分跃度对采样和接触尖峰敏感，不能代替解析参考界。

实际角速度主要折角明显变圆，但并非所有指标都下降：松爪速度尖峰和全程腕部力矩峰值略高；抓紧、松爪以及阶段附近仍有接触/耦合瞬态。最终最大跟踪误差 0.009342 rad，未触发跟踪暂停。最终抽屉残余位移 -0.162575 mm，在原 ±2 mm 判据内，稳定闭合验证通过。

实模型密集路径验证最大位置偏差约 1.9 μm；测试门限为 5 μm，并检查姿态误差和解析关节限位。该结果对应本次路径测试范围，不能泛化为任意任务的统一误差保证。

证据：run/drawer-smooth-20261018/comparison.json；velocity-comparison.png 为 200 Hz 实测对比，descent-detail.png 为 J4 下降参考/实测与差分对比；recorded-velocity-comparison.png 使用与平台数据页相同的两条正式录制的 50 Hz 原始样本，图中未滤波。
