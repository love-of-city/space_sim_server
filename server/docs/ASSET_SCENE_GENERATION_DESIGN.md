# 从资产库生成卫星表面操作场景（设计草案）

2026-10-29 用户确认：主要在卫星外表面安装操作目标。场景由机械臂、夹爪、卫星、操作组件与任务配置共同组成。本文是下一阶段设计，不代表任意机器人或任意卫星已可接入。

## 生成顺序

1. 选择具有已验证控制接口的机械臂、夹爪及卫星安装位，确定机械臂基座相对卫星的变换。
2. 根据机械臂、夹爪能力选择任务类型及完整操作组件。插头/插孔、螺栓/螺纹孔等兼容关系必须保存；取件座与初始插头相对位姿作为一组保留。
3. 在卫星外表面可安装区域中采样位置及绕表面法向的朝向。载荷、配对、安装与姿态约束不满足的组合不进入布局采样。
4. 检查目标安装区域、机构运动包围区域、夹爪张开空间，以及接近、操作、松爪与撤离的末端姿态/路径。
5. 通过整臂 IK 与碰撞检查后生成具体模型；原生动力学执行单独判断接触、载荷和任务完成。插头沿用 40 N、4 Nm 及连续超限 0.15 s 的保护规则。
6. 保存完整已解析场景、资产版本/哈希、基座与各目标坐标系、配对关系、初态、检查结果、采样参数和拒绝记录；固定场景重放不重新采样。

## 可放置区域

候选位置属于“卫星允许安装的外表面”与“该基座安装条件下机械臂可达的区域”的交集。最终可接受对象是安装位姿，而不仅是表面上的一个点。

同一表面位置可能允许一个朝向、却不允许另一个朝向。需要验证整个任务的所需姿态和运动，不能把可达球壳或 TCP 位置点云直接当成可操作区域。目标装好以后，其安装底座可以接触卫星表面；夹爪与机构活动部分在表面外侧运行。太阳翼、天线、传感器视场、禁装面和其他任务机构属于明确障碍或禁用区域。

优先使用保守几何筛选，再对候选做整臂检查。抽屉拉开、锁紧杆摆动等机构扫掠区域也必须计入。操作按顺序执行时，不同任务的空闲操作区域可以重叠，但不能与别的实体机构相交。

安装接口还必须真实存在于碰撞几何中。把插孔模型放在完整实心卫星外壳表面，并不会自动得到可插入的孔。优先把接收孔、支架和必要深度封装为完整操作组件；确实需要穿入卫星内部的接口，需明确允许的开孔、内部占用及对应模型变体。

## 资产库需要的记录

| 资产 | 必须提供的信息 |
| --- | --- |
| 机械臂 | 模型、基座安装接口、关节约定/限制、控制适配器、末端坐标系、工具兼容性、碰撞几何和验收状态 |
| 夹爪 | 安装变换、张开范围、手指/连杆碰撞几何、抓持范围和任务兼容性 |
| 卫星 | 表面与碰撞几何、允许的机械臂安装位、目标安装面片及法向、禁装区域、可承受的任务接口 |
| 操作组件 | 组件内部的机构与配对接口、安装底面、操作/抓持坐标系、关节状态范围、机构扫掠区域、成功条件和载荷限制 |
| 场景配方 | 机械臂与工具候选、目标类型/数量范围、卫星与安装面候选、采样范围、检查版本、随机种子及划分规则 |

机械臂不能从所有文件中无条件均匀抽取；只能在与所选工具、控制接口和任务兼容的已验证资产中抽取。已有任务操作臂与对接臂职责应分别记录和选择。先完成现有 SARM 的卫星表面操作，再逐个加入其他经过适配与验证的机械臂。
