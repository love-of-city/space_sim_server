# 启动入口清理

仓库根目录的八个 CMD 文件只是对既有 PowerShell 命令的重复包装，部分旧入口还绑定了特定机器路径。本次删除这些文件，部署、启动、停止及访问资料命令统一通过 scripts 中的实现调用；更新当前文档、提示和入口回归测试。

停止后台进程时，模块名相同不代表属于本仓库。孤立后端清理现在同时核对当前仓库或父工作区的私有 Python 路径，以及进程启动时间；不清理其他工作区和无法确认归属的共享解释器。新增隔离回归覆盖同模块、相似路径前缀、正反斜线和未知解释器。

验证：在云电脑运行完整基础 CI，726 passed、44 deselected；包含入口跨目录调用、异常退出、并发锁、凭据保护和新增进程隔离检查。数值算法与渲染实现没有修改，既有完整交会验收数据保留。
