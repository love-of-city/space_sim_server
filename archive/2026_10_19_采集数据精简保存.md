# 采集数据精简保存

完整抽屉轨迹原目录约 186.1 MiB，其中两路视频约 70.3 MiB；重复审计 JSONL 和主表内完整 JSON 字符串占据大部分剩余空间。

新录制通过 `config/recording.json` 默认启用 compact 保存，主表保留训练数值，完整相机元数据及必要任务/物理上下文改为有界分块 Zstd Parquet，200 Hz 力去除每行重复的传感器身份。诊断模式保留原布局。自动录制默认关闭全量 trace，独立物理诊断入口仍兼容原 trace 行为。视频编码和采样设置不变。

查看器、采集验收、配置 API 与独立 writer 进程传递配套适配；新记录验证数值源摘要、原始力摘要、会话/帧/时间配对和完整视频，旧记录继续原有 JSONL 验收。

真实历史样本的独立精简副本为 83343833 字节（79.5 MiB），较 195154087 字节减少约 57.3%；6417 主帧、12834 相机记录和25665力样本比较通过，两路视频内容 SHA256 不变。官方 LeRobot 首/中/尾随机读取与平台查看器同步通过。原始数据、报告和视频不提交 Git。

测试涵盖官方读写、小样本真实视频编码、200 Hz 时间轴、可选字段跨 Parquet 分块、数值篡改拒收、原始照片开关、旧格式和独立 writer 进程。完整样本未重新运行 UE/物理，不将转换验收报告为新的仿真速率测试。

最终定向回归两组合计 97 项通过，Ruff 与改动文件的 diff 检查通过。额外修正旧断线测试在 Python 3.13 下先等待 listener 关闭、后关闭已接入连接造成的死锁；先关闭连接再有界等待，不改变生产通信逻辑或原有测试断言。
