# 自动采集噪声开关与随机化验收

日期：2026-10-18。分支 feature/drawer-speed-profile。延续本地抽屉平滑任务，未提交或推送。没有修改原始 MJCF/STL 或 UE 二进制。

## 实现范围

自动采集新建表单增加初始化开关和八组独立配置：关节观测噪声、固定测量偏置、动作扰动、关节观测延迟、六维力噪声、外部扰动力、光照随机化、动力学参数随机化。初始化仍默认 ±10°，其余默认关闭。参数范围、默认值与字段目录统一来自 backend/space_arm_platform/collection_randomization.py；未知字段、非法数值和非布尔开关在启动前拒绝。

配置随 API 请求、持久批次和每个 worker 的源场景传入采集脚本；每次尝试用自己的 seed 采样。simulation/scripted_tasks/randomization.py 拆分独立 PCG64 随机流，保存实际偏置、光强、质量与摩擦倍率。关掉另一个选项不会消耗其他选项的随机序列。初始化关闭也适用于 CLI 源场景。

simulation/scripted_tasks/disturbances.py 负责动作、外力和观测层：动作加入低通 OU 目标偏差并保留关节限位；外力以 BSK CmdForceInertialMsg/CmdTorqueBodyMsg 接入原生步进器，作用于指定刚体质心。任务保护与脚本闭环继续使用真实状态，记录中的 action 是实际施加的关节参考。

观测噪声只改变录制测量；关节延迟在 200 Hz 历史缓存上取样，保留源时刻，不延迟 RGB 或六维力。带噪六维力从同一物理样本、同一种子生成，50/200 Hz 共用结果，保留 ground_truth_force_n/torque_nm；共享 JSON Schema 和写入器的传感器身份比较同步更新。6+1、50 Hz 双相机 1024×1024、200 Hz 六维力、400 Hz 一子步保持原规格。

动力学随机化生成每条独立的 MJCF 变体，质量和惯量同倍率，几何及原资产不变，显式接触 pair 摩擦同步处理；BSK 与 MuJoCo 同时加载变体，姿态配置复制到变体目录，渲染仍引用原几何资源。当前仅支持 standalone MJCF，无 include。光照走既有 UE 太阳光强接口，无需重新编译 UE。

## 使用与边界

入口：自动采集 → 新建采集 → 噪声、扰动与环境随机化。当前已运行的 8000 后端仍为修改前启动的进程，未中断用户服务；重启平台后端并刷新网页后加载新目录。前端遇到旧后端会提示重启，不能悄悄提交不受支持的开关。

噪声默认值是工程试验起点，未经真实硬件标定。测量噪声和延迟作用于录制观测，脚本仍使用真值执行及验收，不能声称完成带噪策略闭环鲁棒性验证。初始角度随机化、物理扰动会实际改变运动；较强扰动可能触发原保护或任务失败。物体初始位姿、初始速度随机化和相机/六维力延迟不在本次范围。
