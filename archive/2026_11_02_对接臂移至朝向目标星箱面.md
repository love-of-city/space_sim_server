# 对接臂移至操作星朝向目标星的箱面

用户确认对接臂可移至操作星面向目标星的一面，并要求操作臂确实安装于操作星。
先核实 square-v2 XML 和 UE 适配器的源父级解析：两臂均为 cubesat_bus 子树，
操作臂没有装在目标星上。旧对接臂底座在 -Y 面，而目标星位于操作星 +X 方向。

本地候选 `D:/mingti/outputs/facing-capture-arm-20261102/facing-v1`：

- 对接臂 bottom_mount 位置从 `(0.4405122094,-0.11,-0.475249368493)` 改为 `(0.6,0.2,-0.35) m`。
- 四元数 wxyz 为 `(0,0.7071067811865476,0,0.7071067811865476)`，根部轴向朝 +X。
- 操作臂 link1 位置 `(0.2,-0.2,0.25) m`、原支座、全部结构、初始关节角保持。
- 目标星及两个任务盒沿用 square-v2；真实接口和原靶标保持。对接臂重新求解关节姿态，夹持原接口。
- 相机本体安装不改；对接臂腕部相机随臂姿态改变，不应宣称它的世界位姿不变。

构建器新增显式 capture-mount 根部位姿选项。独立 XML 核验保留旧基线记录，
只有声明的固定根部 pos/quat 可变，臂段、关节、操作臂与支座完整比较。
新增两臂根部都属于操作星的检查，防止相同子树被重挂到目标星仍获通过。
登记器验证声明/实际根部位姿、单位四元数、父级和后代结构；保留旧无改装证据的兼容路径。
