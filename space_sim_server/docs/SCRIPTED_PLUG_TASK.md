# 圆柱插头自动搬运与插入

任务对象为当前 SARM 2026-10-12 模型的 `cylindrical_plug`。夹爪从初始取件位拿起插头，搬运到前方单独的装配孔，插入后松爪撤离。取件位和目标孔分别从 MJCF 的 site 读取，并转换到卫星本体系；不是把插头放回取件位。

## 目标与运行

默认选择 `cylindrical_insert_40p5`（标称直径 40.5 mm）。插头轴径约 40 mm，模型保留原始碰撞、摩擦及约束。该孔中心在卫星本体系为 [0.535, 0.355, 0.005] m，取件位标记为 [0.3695, 0.33003, 0.005] m。

在服务端目录运行：

```powershell
& $env:SPACE_SIM_PYTHON collection\run_scripted_task.py --task cylindrical_plug_insert --scene run\scenes\<你的场景ID>.json
```

完整 UE 双相机录制：

```powershell
& $env:SPACE_SIM_PYTHON collection\record_scripted_task.py --task cylindrical_plug_insert --scene run\scenes\<你的场景ID>.json
```

默认独立端口为 18766/18767/15558/18888；如已被其他任务占用，可指定 `--control-port 19766 --capture-port 19767 --render-port 16558 --signalling-port 19888`。脚本不会关闭占用端口的其他进程。录制使用场景配置副本，沿用其操作者、轨道、光照和初态，不接管网页中的实例。

录制前固定预运行 6.466666667 仿真秒，然后等待相机准备完成；等待期间不继续推进物理状态。离线对照可传入同样的 `--warmup-sim-seconds 6.466666667`，避免墙钟启动时延影响接触初态。

输出分别位于 `run/plug-task/`、`run/plug-recording/`；数据集仍在 `data/episodes/`。通过 `--target-site cylindrical_insert_40p1` 可选择另一个前方孔，但 40.1 mm 孔不属于本次成功验收范围。尺寸、抓取偏置和速度参数改变后须重新验收。

## 控制与真实物理

阶段：停稳、留出高度、到取件位上方、转向、张开、下降、夹持、抬起、搬运、到孔口上方、对准、插入、保持、松爪、撤离、最终检查。

- 外层物理 240 Hz、默认 implicitfast 1 子步；任务及录制 30 Hz。可用 `--substeps` 显式设置子步数。
- 六轴参考最大速度 0.08 rad/s，搬运规划最大平移速度 0.025 m/s，插入推进速度 0.002 m/s，侧向撤离规划速度 0.01 m/s。
- 搬运使用连续 IK 与五次时间缩放。对孔和插入读取插头相对卫星的实际位置、姿态，再通过机械臂 Jacobian 修正执行器参考。不会直接写入物体姿态或增加抓取焊接。
- 插头在夹爪中可能有偏移，所以目标末端姿态由当前夹爪—插头关系计算；共同轨道速度、卫星平移和转动在读状态时剔除。
- 原始腕部载荷持续 0.15 仿真秒超过 40 N 或 4 N·m、传感器不可用、夹空、滑脱、不可达或阶段超时均报失败。此版本是位姿反馈与载荷保护，并非阻抗/导纳力控。
- 松爪速度降为 0.05 rad/s，开至 0.65 rad 的参考角；在仍接触时补偿释放引起的插头位移，避免直接快速张开造成轴向退出。释放后沿两指之间的切向侧撤 0.12 m，减小向上收臂带来的自由基座轴向反冲。

## 成功标准

必须完成实际抬起、搬运、释放和撤离，随后在最多 90 秒停稳窗口内持续 2 秒满足：

- 插头轴线在孔口平面的径向误差小于 0.4 mm；轴线偏角小于 0.01 rad。
- 插入深度大于 68 mm，法兰基准面与孔口平面距离在 ±1 mm 内。
- 相对平移速度小于 2 mm/s，相对角速度小于 0.03 rad/s。
- 夹爪保持释放开度，末端在台面平面内已离开孔轴至少 0.09 m。

这里的“到位”是该模型及容差下的短期状态判定，不等于有锁止结构或长期不会漂出。动力学验收保留真实接触参数，不能用改孔径、关闭碰撞或松宽失败标准替代通过。

## 代码与数据

- `simulation/scripted_tasks/plug_insert.py`：模型目标解析、策略、路径与状态验收。
- `simulation/scripted_tasks/native_state.py`：独立的只读状态适配，将自由插头状态转换到卫星本体系。
- `collection/run_scripted_task.py`：所有脚本任务共用的动力学诊断入口，通过 `--task` 指定任务。
- `collection/record_scripted_task.py`：复用现有 UE、CaptureLifecycle、EpisodeRecorder 及 LeRobot 写入流程。
- `tests/test_scripted_plug_task.py`：目标坐标、禁止原位目标、实际插入验收、过载/传感器失败、共同运动不变性及日志序列化测试。

训练数据保持既有 22 个 LeRobot 特征。自动任务状态放入已有 `observation.platform_json.scripted_task`，包含目标孔、插头位姿、孔口偏差、插入深度与阶段；action 仍为采样时实际保持的八维执行器参考。相机与状态按源帧号、仿真时刻及会话配对，不从诊断轨迹生成替代图像。
