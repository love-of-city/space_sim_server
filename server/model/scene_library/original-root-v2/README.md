# 当前本地双臂模型快照（2026-11-03）

这是本机仿真平台已登记的 `original-root-v2`，保存当前模型供后续修改及 Linux 接入。
两个机械臂均在操作星上；对接臂通过理想锁定约束保持独立目标星，操作臂恢复原竖直根部。
两个内嵌任务盒呈 L 型。原接口、靶标与原系统相机保持当前已安装状态。

- `preheld-dual.xml`：完整 MJCF，资产路径相对于本目录；共引用 1613 个不同网格文件。
- `meshes/`：26 个内嵌任务盒开槽后的网格；其他网格复用仓库中已有模型。
- `initial-scene.json`：共享初态；`tasks.json`：第 2、4 类共 8 个任务初始化。
- `ue-catalog.json`：186 项已有 UE 网格的来源哈希与资源路径；不是已编译 UE 资产包。
- `manifest.json`：源版本哈希、依赖文件哈希和未验收项目。

## 准备运行文件

先在仓库根目录执行 `git lfs pull`，然后进入 `space_sim_server`：

```sh
python tools/prepare_saved_model.py --output run/saved-original-root-v2
```

输出目录必须是新目录。脚本校验全部依赖，并生成适合当前机器的绝对路径模型、
初态、UE 目录和 `imported_scene_library.json`，不会修改正在运行的平台。
在完成 UE 资产导入后，可备份已有 `run/imported_scene_library.json`，再将输出索引安装到该位置。
索引只包含本快照的第 2、4 类八项配置，不含第 1、3 类。
UE 需要根据目录中的模型源文件重新导入对应资源；不要将目录生成成功当成 UE 导入成功。
平台启动方式沿用服务端 README，启动后选择对应的场景库任务。
