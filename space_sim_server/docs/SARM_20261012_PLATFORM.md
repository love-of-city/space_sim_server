# SARM 2026-10-12 动力学接入

网页选择“新版 SARM 与完整任务盒（2026-10-12·实验）”，采用“指定操作姿态直接启动”。当前不支持旧模型的自动展开、离线姿态规划或训练随机化方案。旧模板保留原模型和滑动抓夹协议。

## 权威模型与运行库

- 原始交付：`model/SARM_mjcf_20261012/SARM_convex.xml`，保持原始字节；同目录包含原始网格及螺纹插件源码。
- 平台派生：`model/SARM/platform/sarm_20261012.xml`；由 `tools/build_sarm_20261012.py` 生成，旁边的 manifest 记录来源、哈希和适配项。
- 真实执行：Basilisk/MJScene + 本地 MuJoCo 3.7.0 implicitfast，240 Hz 主时钟、每步至少 5 子步。MJScene 发布状态，UE 读取同一状态进行渲染。
- `tools/build_sarm_plugin.py` 使用当前 Basilisk 的 MuJoCo DLL，构建 `sarm.sdf.two_start_thread`。加载前校验运行库版本、源码和 DLL 哈希。构建结果在忽略目录 `run/native_acceleration/`，不提交 DLL。
- UE 资产目录生成只解析 XML 中的网格、材质和可见性，不编译动力学模型；该进程无需加载螺纹插件，也不会为了导入网格再加载另一份 MuJoCo。实际仿真仍通过上述插件与 ABI 校验。运行时的网格姿态补偿保持原行为。
- 当前模型含 68 个 qpos、61 个 qvel、2346 个编译后 geom。透明碰撞几何参加物理计算，不作为重复可见物体导入 UE。

派生模型将原固定基座改为自由基座，将原世界固定的抽屉装配附着基座；保留机构层级、内部关节、质量来源、约束、tendon 和 SDF。另增加平台的三只反作用轮、独立地面验证星及相机。这些附件确实增加系统质量。源基座没有显式 inertial，按源几何编译得到质量属性；姿态模块使用相同编译模型的质量与惯量，不凭空补旧基座质量。

## 在轨阻尼适配

源文件三种插头的 free joint 含 `damping="5"`。这是相对世界坐标的自由运动阻尼，并不是插头相对插孔的阻尼。共同平移时，它会单独制动插头；本机原生复现中，仅加入 `[0.01,-0.004,0.002] m/s` 的共同速度，就在约 0.0083 秒触发 BADQACC（航空插头转动自由度）。仅初始化位置、零速度时不发散。

派生模型把这三个自由关节阻尼改为 0，逐项记入 `orbital_free_joint_damping_overrides`。原文件不变；螺栓、紧固件原本使用 freejoint，未施加此项覆盖；机构内部相对关节阻尼、摩擦和碰撞参数保持原值。共同漂移回归和实际在轨启动均验证了该修改。不得把阻尼恢复到 5 来模拟插孔摩擦，应在接触或相对约束层建模。

## 控制与采集语义

六轴继续使用现有笛卡尔 IK 与限位保护。四连杆夹爪使用源 `ee_fingers_position` tendon 位置执行器，两个主动铰链为 `ee_link11_joint`、`ee_link12_joint`，参考值互为相反数；从动连杆由源 equality 约束求解。驱动角范围 0～1 rad，初始最大指令速度 0.2 rad/s。未标定为指尖间距。

网页 R/F 沿用开合输入。后端新增 `gripper_drive_velocity_rad_s`，观测提供驱动角、速度及目标角；此模型不输出伪造的米制手指位移。LeRobot 的 8 维状态和动作是六轴角度加两个主动铰链角度，全部为 rad；元数据记录模型版本、SHA256 和 MuJoCo 运行库版本。同一 episode 禁止切换模型身份。

## 卫星外覆与贴图单位（2026-10-13）

新版 `base_link_mujoco.stl` 使用毫米，MJCF 通过 `scale="0.001 0.001 0.001"` 转成米；原来的 PBR0110 外覆 OBJ 已按 UE 厘米烘焙。外覆若直接继承源几何的缩放，会缩小 1000 倍并藏进卫星内部，不能仅用提高照明来处理。

Runtime 的可视外覆现在继承几何位置和旋转，但使用独立的厘米尺度。旧米制 OBJ 和新版毫米制 STL 都保持外覆世界尺度为 1。外覆无碰撞，不修改 MJCF、接触、质量或采集时间语义。

已用原始 OBJ 与原始二进制 STL（毫米转米）逐项比较外覆的 10 个支撑面：主箱体四侧及底面、下部箱体四侧及底面，边界在 0.01 mm 容差内一致。主箱体为 x=[-0.2,0.6]、y=[-0.11,0.64]、z=[-0.49,0] m；下部箱体为 x=[-0.15,0.45]、y=[0.065,0.465]、z=[-0.69,-0.49] m。顶部机械细节并不相同，原外覆在顶部保持开口。本检查证明外覆支撑面的兼容性，不代表两套机械细节逐三角形相同。
