# 全局相机固定机位随机初始化

完整 `sarm-task-box-20261012` / `sarm-task-box-20261012-sdf` 操作台支持 5 个离散机位。
新场景或每次自动采集尝试开始时，从中等概率选择一个；运行期间及一键复原均重放已保存的机位。
它固定在卫星本体坐标系，随卫星一起运动，不跟踪某个随机摆放的操作件。

以下位置以台面中心为原点，轴方向与 `task_box_base` 一致，单位为米。台面中心在
`cubesat_bus` 坐标系中为 `(0.35, 0.34, 0)`，台面尺寸为 450×550 mm。

| 机位 | 相对台面中心的 X / Y / Z | 朝向 |
| --- | --- | --- |
| P0 原安装点低机位 | −0.53 / −0.07 / 0.30 | 向下约 24° |
| P1 −Y 外侧安装点 | −0.53 / −0.28 / 0.30 | 向下约 22° |
| P2 +Y 外侧安装点 | −0.53 / +0.22 / 0.30 | 向下约 23° |
| P3 侧边中段安装点 | −0.53 / +0.08 / 0.30 | 向下约 24° |
| P4 +Y 内侧安装点 | −0.45 / +0.24 / 0.30 | 向下约 25° |

以上为 v4 预设，5 个机位统一在**卫星实体台面上方 30 cm**。相机的垂直投影及半径
15 mm 的安装范围均落在原始 `base_link_mesh` 的 z=0 实体表面上。P0 恢复原相机的 XY
安装位置；其它安装点也在同侧实体台面内。运行时约束安装区域，测试另用实际 STL 三角面
逐点验证，不以外接矩形或仅有本体父坐标系作为安装成立的依据。

P3 的本体坐标为 **(-0.18, 0.42, 0.30) m**，距机械臂基座轴线约 **45.7 cm**。
它替代 v3 中靠近基座的 P3（本体坐标 `(-0.10, -0.05, 0.30) m`，轴线距离约 11.2 cm）。
新预设增加安装点与基座轴线至少 18 cm 的静态排除条件；该条件和台面检查均不等于
机械臂全运动范围的碰撞验收。当前相机没有实体支架及外壳碰撞模型，仍需结合任务轨迹检查。

全部朝向台面中心上方 6 cm，不加滚转；为兼顾低机位、实体安装与操作区完整入镜，
视野从旧版 80.5929896518° 调整为 **90°**。台面及其上方 18 cm 的包络通过视锥检查，
距画面边界至少留 15% 余量。沿用 1024² 录制、
相机 ID 与采样率；腕部相机的位姿保持原配置。MJCF 相机为 −Z 朝前/+Y 朝上，
协议相机为 +X 朝前/+Y 向左/+Z 朝上，预设保存的是经过转换的协议四元数。

## 网页与命令行

- 场景实例：勾选“全局相机随机初始化（5 个固定机位）”，再创建场景。旧实例及未勾选时沿用原相机。
- 自动采集：同名开关默认勾选。每次尝试根据本次 seed 重新选择，允许相邻尝试选中同一机位。
- 单批脚本：`collect_drawer_cycles.py`、`collect_plug_tasks.py`、`collect_scripted_tasks.py`
  增加 `--randomize-overview-camera`；`--no-randomize-overview-camera` 显式关闭；不传时继承源场景。
- 并行采集：`collection.json` 的 `randomize_overview_camera` 控制，随仓库提供的配置为 `true`。
- API：`POST /api/scenes/start`、`/api/scenes/instances`、`/api/collections`
  接受严格布尔字段 `randomize_overview_camera`；为兼容旧客户端，省略时为 `false`。

这些机位按当前完整任务盒标定；其它模板和锁紧件局部特写 demo 不接受此开关。
网页/后端更新后需重新构建前端并重启对应服务，新建场景或批次生效；已运行实例不切换。
本功能复用既有渲染相机协议，不需要新增或重新编译 UE 功能。

## 记录与验收

新场景使用 `space-arm-overview-camera/4` 和独立随机流
`space-arm-overview-camera-presets-v4`，相同版本和 seed 可复现，
不移动关节、布局、轨道、噪声和光照的抽样流。
场景及 episode 元数据的 `scene_instance.overview_camera` 保存版本、机位 ID、选择 seed、
本体位置、安装点、安装高度、协议朝向、视野和参考中心。自动采集 attempt summary 另存 `overview_camera`，
`collection_config.overview_camera_randomization` 保存同一份记录。

录制加载时校验配置与 seed/版本相符，不在加载、重置和逐帧渲染时重新抽样。
自动采集验收还逐帧核对 UE 回传的实际全局相机外参与同帧卫星姿态、预设相符，
避免只改了元数据、渲染仍使用旧机位的记录进入成功集合。
机位随机化与操作台布局池可组合；几何视野覆盖不代表所有动作过程都无遮挡，正式批采集仍需检查视频。
历史 v1（台面上方 50–72 cm）、v2 和 v3 的场景、数据仍按保存的版本及抽样流校验、重放，
加载和重置不会改写记录；新建场景或下一次采集尝试采用 v4。
v2 的视野和外参检查遗漏实体安装条件，存在机位垂直投影超出本体的问题，已被 v3 修正。
未开启随机化的场景仍使用模型自带相机。

历史 v1 的真实短录制验收见根目录 `archive/2026_10_24_全局相机固定机位随机初始化.md`；
v2 的历史实拍见 `archive/2026_10_24_全局相机30cm机位调整.md`，
v3 的安装点修正见 `archive/2026_10_24_全局相机实体安装约束修正.md`，
v4 的 P3 重定位与实拍见 `archive/2026_10_24_P3机位远离机械臂基座.md`。
