# 粗碰撞体：启用待抓取卫星内部接触

更新：2026-09-09。当前默认模板为 `sarm-ground-validation-self-collision-grasp`，运行文件为
`model/SARM/platform/sarm_ground_target_self_collision.xml`。这是粗碰撞方案，不加载高精度 `flexcomp` 三角面。

## 哪些接触已开启

- 外侧板 ↔ 卫星本体。
- 外侧板 ↔ 固定内侧板。
- 机器人/夹爪 ↔ 目标的原有外部接触保留。
- 固定本体与固定内侧板属于同一焊接刚性组，不增加它们之间的内部接触。

新模板没有目标 body 对的 `<exclude>`。通过两条具名 `<contact><pair>` 指定内部接触，
不用全局关闭 MuJoCo 的父子刚体过滤，从而避免意外改变 SARM 其他关节附近的碰撞规则。

## 为什么是五个粗盒，而不是直接删除旧排除项

旧三个外部 AABB 在铰链附近相交；直接用于内部接触会产生初始假接触。
因此保留它们的形状、位置和接触参数，另加两个只用于内部接触的板件代理：

| 碰撞体 | 作用 |
| --- | --- |
| `capture_target_collision` | 原本体粗盒；用于机器人接触，也与外侧板内部代理配对 |
| `satellite_inner_panel_collision` | 原内侧板粗盒，保持原外部抓取接触 |
| `satellite_outer_panel_collision` | 原外侧板粗盒，保持原外部抓取接触 |
| `satellite_inner_panel_internal_collision` | 新增内侧板内部接触粗盒 |
| `satellite_outer_panel_internal_collision` | 新增外侧板内部接触粗盒 |

两个内部代理只沿板件局部 X 缩短靠近铰链的一端，其余维度保留原包围盒尺寸。
取原板件相对铰链的最大横向半包络 **14.95001 mm**，加 **1 mm** 的近似间隙，
形成铰链两侧各 **15.95001 mm** 的简化避让区；零位两个内部板代理之间相距 **31.90002 mm**。
这些数值是**碰撞代理的建模近似，不是真实铰链间隙，也不是视觉模型被切掉了这一段**。
该区域仍保留原外部抓取粗盒，但不使用重叠的盒端部计算板件间接触；真实铰链销轴/叶片/止挡尚未重建。

原三个外部粗盒使用 `contype=2 / conaffinity=1`，继续匹配机器人 bit 1，避免目标外部盒彼此产生重复的自动接触。
两个内部代理使用 `contype=0 / conaffinity=0`，**并不是禁用了其显式接触**：它们通过 `<pair>` 参与指定配对，
不重复计算夹爪接触。两个 pair 均使用 `condim=6`、`solref="0.01 1"`、零 margin/gap 和原粗盒对应的摩擦参数。
所有新增代理都是 `mass=0 / group=3 / alpha=0`；无新增刚体/关节/柔性自由度，208 个可视网格不变。

质量与惯量仍为原来的合成 8+1+1 kg 方案；主卫星、轮、机械臂、相机、控制器、2 ms 时间步和星历/轨道逻辑均不变。
铰链仍是无驱动、无阻尼/弹簧且 `limited=false` 的被动关节；阻挡来自接触力，不是偷偷添加角度限位。

## 兼容与使用

为避免改写既有数据集/实例的物理语义，以及破坏高精度试验的源文件指纹，新模式使用独立模板和派生 XML。
原 `sarm-ground-validation-grasp` / `sarm_ground_target.xml` 仍是三个外部粗盒、无目标内部接触；高精度试验文件也保持不变。
**已保存的旧实例不会自动开启内部碰撞。** 重启使用旧代码的后端并刷新操作台，选择
**SARM + 地面验证星（粗碰撞体·内部碰撞）** 创建新实例。观察 `collision_model=coarse_boxes_with_target_self_collision`。
主平台未被自动重启；没有提交推送。

`tools/build_sarm_ground_target.py` 同时生成/检查两种粗盒版本，不重写内容未改变的旧文件。
参数与几何变更记录在新 XML 同名 `.manifest.json` 中；不要只手工修改派生 XML。

```powershell
python tools/build_sarm_ground_target.py --check
python tools/select_sarm_scene.py --check
```

## 验证边界

- MuJoCo 3.7 独立目标验证：零位静置无接触/自发运动；±90° 范围内无铰链假接触。
- 静态角度扫描两组 pair 都能产生有限、非零法向力。约 +140° / -95° 开始出现接触，**这只是粗盒形状的结果，不是工程行程范围**。
- 连续 ±1、±5 rad/s 初速及 ±0.1 N·m 恒定铰链力矩，分别推进 10 s：出现接触阻挡，未整圈穿过；测试断言穿透小于 1 mm、状态有限且没有 MuJoCo warning。
- 完整组合：128 组随机初态无目标相关初始接触；两指仍能产生接触力，编译 geom 顺序与渲染元数据一致。
- 真实 BSK/MJScene 正、反 ±1 rad/s 初速分别推进 5 s：相对角度未穿过一整圈，接触后转速反向；15 个 body、8 路臂控制和姿态保持正常。
- 真实默认遥操作 → Hub/渲染协议通过：208 个目标可视 mesh、5 个隐藏粗盒、4 个渲染帧和3条合法观测，轨道/天体一致。0.1 s 物理推进约用 0.25 s 墙钟时间，含冷启动约 28.24 s；不是实时性能承诺。
- 共 138 项相关回归通过（后端/选型 41、MuJoCo 几何/旧试验 40、独立 BSK 4、前端 53），前端构建、生成器/源文件指纹和 PowerShell 语法检查通过。
- 本轮复用已导入的 113 个 UE 可视网格，未重新导入或启动 UE，也未做 GPU/浏览器视频验收；下一次正式启动会按新实例模板校验资源映射。
- 过程及报告在本机 `run/coarse-self-contact-20260909/`；原始 CAD、旧粗盒 XML 与高精度几何均未改动。

这些验证不是任意力、任意高速或长时间稳定性的保证；也不代表碰撞外形精确匹配 CAD。
原始三角网格精度、真实铰链机构、工程质量/摩擦参数、完整抓取搬运和浏览器视频仍需要另外验收。
