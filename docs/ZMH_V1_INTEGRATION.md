## 冲突取舍

- 保留主线单次 `ik_pose`/`strict` 求解，不恢复自动零空间返航；保留机械臂/夹爪独立使能和无输入时跳过 IK。
- IK 之后组合本地 `JointReferenceGovernor`。它可根据实际关节误差/饱和缩放速度，而 `MotionSpeedMonitor` 仅做诊断，不能触发运动或代替安全检查。
- 松键卸载仍要求明确许可、指令新鲜和无安全原因。只操作夹爪不触发机械臂卸载。
- 将参考保护遥测加入主线 `AuthoritativeObservationModel` 的同一时刻快照，不重新启用旧的外层循环延迟采样，保留 LeRobot 的帧时间一致性。
- 保留主线默认启用数据采集的配置和 1/2/5/10 Hz 采集限制，同时加入本地可验证的动力学步长范围。旧运行实例的 `dataset_capture=false` 不因分支整合而被改写。
- 原生离线历史记录默认保留；实时遥操作显式关闭未使用的九路高频历史数组，不关闭后端 LeRobot 数据集记录。
- 进程清理同时保留主线的不可读启动时间保护、本地的退出确认和严格限定项目的残留扫描。
- 更新了要求“大跟踪误差不能限制运动”的上游测试：本分支要求参考保护生效、读写诊断开关不改变控制输出；没有通过删除整个测试文件隐藏分歧。

## 环境和验收边界

主线新增 `lerobot==0.4.4` 运行依赖。原本地测试环境没有 LeRobot、Torch、Datasets、PyArrow、AV 等数据采集依赖；因此涉及真正开始数据集录制的测试不能据此宣称通过。不要为提交分支而覆盖正在运行的仿真 Python 环境；部署整合版本前应准备隔离的完整环境并完成采集验收。

测试及构建结果记录于工作区忽略的 `run/zmh-v1-*.log`。原生仿真测试独立运行，避免 Python MuJoCo 与 Basilisk 的 DLL 冲突。新分支的编译/离线测试不等于公网浏览器视频和 LeRobot 完整部署已经验收。

此前故障诊断、原始实验及在线验证过程保留在根目录 `CONTROL_INSTABILITY_REPORT.md`；其记录对应当时运行版本，不应当作本次所有主线新功能均在线验证的证明。
