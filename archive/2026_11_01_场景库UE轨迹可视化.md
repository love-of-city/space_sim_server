# 场景库 UE 轨迹可视化

用户要求在本地 UE 里观看场景。原有 14/14 是实际动力学/控制的无界面运行验收，不包含 UE 显示。

新增 `space_sim_server/tools/export_scene_ue_replay.py`：独立几何 Python 读取已保存的原生 qpos，通过正运动学导出 bsk-render/2 记录，不调用动力学步进。验证模型哈希、源资产哈希、编译几何所属刚体和网格名称；将源网格重心补偿与缩放保留到 UE。按刚体归并 XML 几何，兼容在子刚体后追加安装支座的场景。原始接触、力矩和任务验收记录不变。

新增 `view_scene_library.py`：从 verified library 选择带关节状态轨迹的操作任务，校验通过回执后按需导出、缓存和打开 UE。本地配置指定 Python、UE 工程、资产目录和缓存；源码不写死 Windows 安装位置。当前操作入口涵盖第 1、2、4 类；第 3 类轨道 NPZ 不属于该格式，尚未接入这个回放菜单。

本机使用已经编译并导入资产的 `captive-fastener` UE 工程作为显示端，发送端及场景来自 `scene-library`。源网格 SHA256 匹配后重建目录映射，不覆盖其他工作树源码或公共目录。局部着色使用该工程现有材质及 MLI 外观层；照明为观察用途，未做图像算法验收。

输出位于 `D:/mingti/outputs/scene-library-20261101/ue-visual-v1/`。`choose-scene.cmd` 选择操作场景，`open-cross-guide.cmd` 打开跨星导向插头转运。首轮实测 UE 已读取 7172 帧、41 个刚体、459 个可视几何；实际窗口显示模型并推进轨迹。已额外导出已连接目标星抽屉操作 1030 帧。UE 启动首轮使用新缓存停顿，切换回已存在的工程缓存后成功；保留首轮日志。

这属于 UE 中的真实轨迹回放，不能称为 UE 实时联动控制、物理对接或完整视觉评测。Linux 启动与资源迁移仍未验证。没有推送。
