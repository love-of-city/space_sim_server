# 2026-10-16 双场景并行采集验证

新增独立基准工具，对比两个完整抽屉循环的 CPU 串行/并行、同模型的 CPU/GPU 接触步进，以及真实 UE 相机录制的串行/并行。详细条件、结果和限制见 [双场景验证报告](../space_sim_server/docs/TWO_WORLD_PARALLEL_BENCHMARK.md)。

GPU 实验在独立环境使用 MuJoCo/Warp 3.16.0，重编译实验插件并校验五种 SDF 公式，不覆盖生产 Basilisk/MuJoCo。GPU 验证只覆盖接触内核，不代表完整 BSK/UE 采集迁移完成。

生产 CPU 测试保留 400 Hz 单子步、脚本/六维力 200 Hz、主数据和两路 1024×1024 相机 50 Hz、七维 state/action。短录制片段按原协议保留 failure/total_simulation_timeout 标签，不混入成功示范。

运行数据、GPU Python 环境、编译 DLL、原始日志和视频只在忽略目录 run/two-world-benchmark 与 run/gpu_parallel_probe 下保存。

## 四实例补充验证

按用户要求将基准脚本的 workers/jobs 参数扩展到 1–4，默认仍为 2。新增 UE 实例计数和系统剩余内存采样，沿用原生产录制器做四路 20 秒同步并发试验。详见 [四实例验证报告](../space_sim_server/docs/FOUR_WORLD_PARALLEL_BENCHMARK.md)，原始输出保存在 run/four-world-benchmark/capture-parallel/。
