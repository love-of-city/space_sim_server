# 圆柱插头插入与卸载修复（2026-10-29）

本次保留原有腕部保护：合力40 N、合力矩4 Nm，连续超限0.15 s停止；保留20 N保持摩擦、原始碰撞、动力学和独立评分条件。仅调整圆柱插头任务控制，不改变导向、航空插头的推进或释放控制。

## 复现与原因

原任务在128.29 s因`wrist_load_limit`失败。插头在最后8 mm进入20 N摩擦区后暂时停住，控制器仍按时间向下推进目标，并积分关节参考。到128 s，参考TCP已比实际TCP低14.25 mm。插头倾斜后，自126.4 s起出现同侧孔壁接触，最终形成持续腕部弯矩超限。

第一版将圆柱插头的轴向目标领先量限制为1 mm，在径向误差达到0.2 mm、轴线误差达到0.002 rad，或载荷达到原保护阈值的75%时停止继续下压，保留对准反馈。它完成了插入，却在撤离时超时：20 N插入载荷所需的伺服预载没有卸掉，松爪后夹爪下沉，`ee_finger1_geom_collision_050`与`base_link_geom_collision_003`碰撞。

最终版本在释放入口一次性记录指令和实测关节。保持夹爪闭合，用最小跃度曲线平滑地把机械臂参考移到当时的实测关节；卸载时间至少1 s，并按原关节速度上限延长。随后保持这个参考再张开夹爪，避免反馈重新积累插入预载。没有写入物体状态、添加抓取焊接或关闭碰撞。

“目标领先量受限”不等于“所有执行器参考误差为零”：克服摩擦需要有限预载；第二步处理的是载荷消失前的预载卸除。

接触诊断为10 Hz抽样，腕部载荷/任务评分为200 Hz；上述接触统计不是逐400 Hz物理步的完整无碰撞认证。
