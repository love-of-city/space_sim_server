# 双任务盒随机初始化接入

用户要求参考 GitHub 任务盒随机初始化，接入已确认的第 2、4 类双臂场景。
已 fetch 并核对 origin/main 98449ee、origin/zmh_linux a489198。参考上游布局池，
保留本地连续外壳、双臂、任务盒外部安装框架和相机，未整体覆盖本地文件。

新增 `prepare_dual_taskbox_pool.py` 串联几何生成/验收、UE 导入、双盒移植及本地
登记。固定布局默认不变；显式启用时按原采集随机流和 seed 选择完整预构建配对。
本地更严格的操作空间规则首轮未找到布局，保留失败日志；后续候选保持完整路径
待验收状态，仅供预览/遥操作，不能进入原采集池或开启数据采集。

首个候选的航空插头就位检查发现约 0.506 mm 的底板碰撞，未放宽 0.2 mm 的
检查阈值。增加参数使底板外侧让位为 0.9 mm，仍位于 1 mm 孔套安装边内；
原插孔、孔套配合表面不变。默认生成参数仍保留 0.25 mm。新、旧产物均留存。

0.9 mm 让位后仍检出约 0.437 mm 重叠，继续定位到原底板凸包跨越独立凸起
形成的虚假区域。生成器改为将原凸包裁到各真实 CAD 凸起包络内，再移动锁扣
支座；未扩大精密孔，也未放宽碰撞阈值。开孔底板改用带孔截面的三角棱柱分解，
避免连续裁切产生数千片细碎凸包。独立测试检查体积守恒、凸性及孔内零填充。

双盒移植对网格名称分别加前缀，避免不同底板孔位复用同名网格；原接触排除
映射到各自箱体。修复相同插件定义仅因 XML 缩进不同而误报冲突的问题。

验收和登记以本机输出目录 `D:/mingti/outputs/dual-layout-pool-20261103` 中的
逐阶段记录为准；测试通过不替代原生几何、真实 UE 或完整路径验收。未推送 GitHub。

本轮登记结果：`registration-v2/pool.json` 包含两种配对，覆盖第 2、4 类全部
8 个现有任务入口。`fixed-a`、`fixed-b` 各自通过 36 个原生孔位/取件位检查
（底板最大穿透均为 0）和独立孔套网格审计。`final-v2/pair-000`、`pair-001`
通过双臂/双盒初始接触、封板间隙和六面封闭检查；装配机位与原初态哈希一致。
两套 UE 底板已真实导入并核对 LOD0 三角面，11 个未变视觉件按精确哈希复用。

实际平台 API 检查记录见 `api-smoke/summary.json`：8 项任务均可生成随机实例，
同种子重复一致、可选到两种配对、关闭随机化仍返回原固定模型，候选数据采集
请求返回 422。未执行完整操作轨迹。生成过程中的失败产物和被中断阶段记录
全部保留；最终登记是几何复验和资产检查后单独执行的恢复步骤。

修复流程日志把不可覆盖证据写函数误用于动态状态文件的问题，改为原子更新
阶段日志，并通过多阶段登记回归测试。另修复增量 UE 导入确认数误用全体单元数
的问题；A 的原逐资产三角面检查已通过，保留原回执及计数更正说明，B 使用修复后入口。

本机实时启动诊断：首轮 UE 就绪检测在 240 秒超时，随后将本地后端启动参数
`--runtime-renderer-ready-timeout` 设为 600（未改仓库默认值或物理阈值）。下一轮
UE 已就绪，但子进程通过 PATH 选择到缺少 pydantic 的基础 Conda Python。
已在 Git 忽略的 `.space-sim-python` 中显式选择原原生仿真虚拟环境包装器；
该环境的 pydantic 与 Basilisk 导入预检通过。失败现场保留在 live、live-v3。

后续实际运行揭示 Basilisk VFS 不接受两个不同目录中同名的碰撞网格，而独立
MuJoCo XML 加载允许这种路径。组合器现在复制冲突文件到带唯一前缀的路径，
逐文件校验字节哈希，并为 UE 视觉件保留同哈希资产映射。新增
`check_dual_taskbox_native_load.py`，直接使用原生 Basilisk 加载模型；流水线和
登记同时要求其成功且模型哈希一致。此检查只证明可加载，不代表任务轨迹通过。

最终登记为 `registration-complete/pool.json`，模型位于 `final-v3/pair-000` 和
`pair-001`，两者均通过实际 Basilisk 加载和初始几何检查。第 4 类航空插头任务
使用种子 101 启动第一种配对，实例 `scene-20261103-212712-8f0604a3`；已取得
匹配该实例且仿真时间超过 1 秒的观测，以及主视图、卫星总览、操作臂腕部、
对接臂腕部四路真实 UE WebRTC 截图，位于 `live-v5/cameras-final`。沿用原相机，
局部遮挡与亮部曝光仍需人工评阅，未宣称所有视角均达到视觉验收要求。
