# 原生抓取接触证据与只读复算

`CaptureAudit` 在显式指定 `output_path` 的原始 `*_force.jsonl` 中增加逐接触原生证据，另写 `*_manifest.json`。既有控制反馈、阶段名和详细身体日志保留；新增记录不调用额外的 `forward`、不积分、不施加力、不修改状态。详细身体日志仍在绝对仿真 300 s 后停止，原始接触与力记录继续覆盖迟至数千秒才开始的抓取。

这项交付提供接触子审计，尚不注册或验收 D54、D55、D62 等完整任务。`physical_hold_passed` 不能代替整个任务的安全、视觉、导航、抓取对象、方法接口或端到端验收。正在运行的旧源码全程试验及旧汇总日志仍按各自版本归档。

## 记录与模型身份

`space-sim-capture-contact-evidence/1` 每行记录：

- 连续序号、绝对任务时间、步进器整数物理时间及已完成步数、原生浮点时间换算的纳秒读回、积分子步数、外部物理状态写入次数。
- 原生夹爪本体四元数及对应轴方向。
- 全部原生接触的几何名称、所属身体及根身体、间距、局部位置、六维接触坐标系力/力矩、接触坐标系、约束地址和读回时间。
- 原控制器 `phase`、`feedback`、汇总自碰撞数，仅供兼容和诊断。

`space-sim-capture-contact-manifest/1` 绑定模型 XML SHA256、几何身份、文件名、400 Hz 周期及实际子步数。评分器重新解析模型，拒绝未展开 include、未命名或重名几何/身体、直接挂在 worldbody 的几何。当前 capture26 团队模型满足此范围；这不是通用任意 MJCF 审计接口。

此 manifest 不能单独证明一次运行的完整性。完整 Benchmark 归档还必须绑定全部日志、模型及网格/运行时指纹、任务配置、回合边界和源码身份；不能只选择一段有利的力日志作为任务结果。

## 物理判据

复算器使用模型解析的身体身份和原始接触力，忽略控制器的阶段、成功声明和汇总反馈：

1. 仅 `cubesat_bus` 与 `capture_target` 间、涉及 `capture_x_piece_*` 的有效求解约束可贡献支撑。
2. 四个不同身体 `jaw_0` 至 `jaw_3` 各自轴向支撑力严格大于 0.1 N；同一爪的多个接触斑不能冒充多个爪，重复有效约束地址无效。
3. 轴向支撑为每个接触法向力非负值乘以“接触法向与原生夹爪轴夹角余弦的绝对值”，再求和。该量沿用现有控制器的支撑负载约定，**不是整个组合体的净外力**，也不包含摩擦分量的轴向投影。
4. 四爪总支撑 4.5–5.5 N 连续至少 20 s，即至少 8001 个相邻的 400 Hz 有效采样。单个物理步断触或超出力带即清零当前连续保持。
5. 任意时刻目标接触峰值法向力超过 10 N，或触发现有服务星自碰撞规则，否决整个文件的通过。自碰撞规则为服务星根身体内一个原抓取臂身体与一个非抓取臂身体间穿透超过 0.1 mm；它不等于完整任务的所有碰撞/禁入区判据。

所有物理数值必须有限；四元数及接触坐标系必须有效。接触与本体读回时钟必须一致。记录缺失、重复、乱序、外部状态写入、过时原生时钟或不支持的格式均不能累计保持时间。

整数物理时钟、步数和绝对任务时间保持恒定偏移；每次增加恰好一个 2,500,000 ns 物理步。COMMAND 槽读到的是已完成的上一物理步，阶段交接的任务绝对纪元也可能非零，因此这两个时间不被强行当作同一时刻。原生 MuJoCo 浮点时间保留实际读回，允许重复浮点加法的保守舍入界；界限若达到四分之一步长就拒绝。保持时长只由整数物理时间计算。当前格式只接受每次审计包含一个原生积分子步的 400 Hz 路线；更多子步需要逐子步证据，不能靠末子步日志声称完整采样。

## 独立复算

在 `space_sim_server` 目录使用项目 Python：

```powershell
python -m simulation.capture_contact_evidence <目录>/contacts_400hz_force.jsonl --model <实际模型.xml> --manifest <目录>/contacts_400hz_manifest.json
```

输出为 `space-sim-capture-contact-score/1` JSON。退出码 0 表示该接触子审计通过；1 表示有效记录未满足保持/安全条件；2 表示记录或身份无效。命令只读取输入并输出结果，不更新原始日志、manifest 或历史评分。旧版只有汇总反馈的文件不符合新格式，不能补写字段后冒充本次原生证据。

基础测试覆盖四爪身份、垫环/错误部位、无效约束、单帧失效、过载/自碰撞否决、缺帧/重复/时钟、原始数值、晚期记录及复算文件不变性。实际原生读回、控制兼容和完整任务路线须分别通过云端物理验收；合成证据测试不构成真实抓取成功记录。
