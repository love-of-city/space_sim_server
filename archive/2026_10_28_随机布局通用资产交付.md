# 随机布局通用资产交付

此前提交了七孔独立着色和随机布局生成代码，但运行入口依赖本机历史 `Saved/AssetImport` catalog 以及未同步的 UE 通用资产。新检出目录仅有原始整体台板时，颜色任务会因缺少七孔独立表面绑定被拒绝。

本次同步 131 个共用部件的 UE 资产（Git LFS），增加 `space_sim_server/config/collection-base-assets.json`，以服务端相对路径记录原始网格，以 UE `/Game` 路径记录资产，并保存两者 SHA。`simulation/collection_assets.py` 在当前机器校验并生成绝对路径 catalog；缺文件、LFS 指针或 SHA 不一致时拒绝继续。自定义/重新导入的资源可显式传入匹配的 `--base-catalog`。

`prepare_collection_layout_pool.py` 和 `prepare_independent_layout_catalog.py` 默认使用交付的通用清单，`--base-catalog` 改为可选。未改变布局采样范围、间隙限制、轨迹验收或池发布条件。每个新 seed 的独立孔面、取件座、匹配底板及碰撞结构由现有生成器重建，12 个视觉网格导入该布局专属 UE 命名空间。颜色在每条数据中按稳定孔身份独立随机。未将任一固定布局、历史池、实验录制、日志或临时生成的布局资产纳入提交。

验证：

- 61 项相关 Python 测试通过，全服务端 Ruff 检查通过。
- 仅使用 Git 暂存区中的 265 个文件（包含实际 LFS 内容）重建另一检出路径，131 项通用资产解析及 SHA 校验通过；不依赖原 `Saved` 目录。
- 新生成 seed `2026102800`（仅 XY 随机）与 `2026102801`（XY 加 ±30° yaw）两套布局，原生几何检查均通过，检查范围内底板最大穿透为 0。
- 两套布局各自重新导入 12 个 UE 视觉网格，逐资产 LOD0 三角形数量校验通过。
- 每套布局测试三个颜色种子，七孔颜色均不重复，着色前后物理 XML 相同。

以上验证的是随机布局资产生成、原生几何及颜色绑定，未在本次运行完整任务轨迹和双相机采集，也未发布新的已验收随机池。既有螺丝接近碰撞等任务问题不由资产补交解决。正式池仍须通过原有轨迹门禁，不能用资产测试结果代替任务成功。
