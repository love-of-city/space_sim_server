# 螺纹操作自动采集

两个任务复用现有 BSK/MuJoCo 权威动力学、夹爪接触、腕部力传感器和 UE 双相机 LeRobot v3 录制。控制器只发布现有八维关节参考，不修改运行中的机构坐标、物体位姿、约束或接触力。脚本默认不因腕力超载中断；真实接触、螺纹导程和关节限位仍参与动力学。

| 任务 ID | 操作顺序 |
| --- | --- |
| `aviation_bolt_insert` | 接近并抓住航空螺丝 → 从初始螺纹孔旋出 → 搬到目标孔 → 对准旋入 → 松爪撤离 → 检查保持 |
| `locking_rod_cycle` | 卡口同轴抓取并旋松 → 松爪换成支撑抓姿 → 放倒到卡扣并释放 → 重抓扶起 → 换回卡口同轴抓姿并旋紧 → 松爪撤离 → 检查保持 |

航空螺丝采用交替旋拧和松爪回腕重抓，避免用单个腕关节连续绕多圈跨越限位。搬运与接近使用平滑位姿路径，接近时同时调整夹爪朝向并张开。空程目标速度为 5 cm/s；螺纹内的轴向速度由实际导程与旋拧速度共同决定，不能按插头的拔插直线速度独立指定。

当前控制器为 `aviation-bolt/2-latch-smooth-regrasp` 和
`locking-rod-cycle/2-coaxial-latch`。两项任务的旋拧抓取都以局部 Y 为闭合轴，
TCP 位于螺丝头局部 Z=-5 mm，使原有 C 形手指卡口与原 CAD 头部卡口接触。
读取原生接触点、接触法线及同一物理子步的刚体位姿，区分卡口、六角头
外侧和颈部接触；不会混用轨道惯性系的消息坐标和近原点接触坐标。

旋拧到每个回腕交接点前先平滑减速；换抓后沿用已发布参考的当前速度和
加速度，不重放上一段反馈速度。一个时刻只由一条轨迹生成机械臂指令，
不会把反馈积分叠加在每帧重置的预规划路径上，也不会因某一帧出现双侧
接触就突然跳过机械臂更新。杆状任务的旋拧与摆杆使用不同抓姿，详见
[锁紧杆采集](LOCKING_ROD_COLLECTION.md)。

开爪跟踪和防脱杆件的位姿参考在指令空间计算误差；自由航空螺丝沿
螺旋线旋拧时使用实测 FK 反馈，补偿孔口接触导致的持续伺服偏差，
避免只转不进、松爪退转。两种模式均用实际关节限制参考超前量，物理
伺服继续使用实测状态闭环。速度误差通过有限响应增益生成加速度，再施加
jerk 限制。不能将速度误差直接除以 5 ms 控制周期：该组合会在固定
目标附近产生约 0.03 rad/s 的持续速度振荡，导致旋拧后无法停稳换抓。
回归测试同时检查加速度、jerk 上界以及固定目标的最终收敛。

航空螺丝每段旋拧保留实测螺纹相位，同时将轴线平滑对齐当前孔轴；
不能把搬运末端残留的倾斜直接当成后续螺旋线的固定姿态。旋转进度
还跟随实测轴向推进，最多领先 0.5 rad（16 mm 导程下约 1.27 mm），
给真实卡口与螺纹间隙留出余量。尖端受阻时逐渐减速，不能空转半圈后
松爪。实测 FK 模式在接近参考超前边界前平滑减速，避免直接截断参考
位置造成速度突变。夹爪脱离后，卸载路径完成减速才交接到回腕或撤离。

回腕只将夹爪松到 0.40 rad，不必每次张到最大。对所有名义回腕及额外半圈加 0.5 rad 的角度包络做原生几何扫描，六角头的无接触开度下界约为 0.3551 rad，当前保留约 0.0449 rad 余量。实际双指脱离且左右开度都达到目标附近后才开始回腕。

## 场景初态和随机布局

航空螺丝初始孔使用对应的物理母螺纹 SDF。任务生成独立模型时会为缺少该螺纹的旧布局补装它，安装位置与朝向跟随初始孔所属单元。

杆状任务使用专门的初始模型：防脱紧固件在挂钩处处于旋紧位置，铰链的合法行程覆盖卡扣。该变体只用于 `locking_rod_cycle`，其余任务保留原初态。运行时读取实际铰链、滑动和旋转关节的原生地址，不能把子体紧固件当成自由刚体读取。

网页“自动采集”从后端任务目录加载这两个任务。位置和朝向随机化仍通过已经校验的布局池选取，不会在运行中移动台面组件。每次初始化使用与实际任务相同的螺纹/锁紧变体做预检；无法到达、关节超限或发生非预期接触的初态会记录为拒绝，不以固定布局静默替代。

预检在独立、私有的原生模型中沿规划路径检查机械臂及机构姿态。私有机构坐标随规划路径同步，允许明确规划的手指与抓取件接触；手腕或机械臂与操作台穿透超过 0.5 mm 时拒绝。运动中的杆、紧固件或航空螺丝与底座或其他模块穿透超过 0.2 mm 时也会拒绝；杆机构自身的挂钩/卡扣接触，以及明确的公母螺纹接触仍保留。旧随机布局池的检查范围可能小于新任务的放倒范围，因此不能仅凭旧池已通过布局检查就跳过本次任务预检。预检不改动正式仿真。

航空螺丝预检先按真实手指/六角头接触几何确定闭合开度，再检查握持旋转。每个半圈还检查额外 0.5 rad 的末段继续旋转包络，用于接近完全旋出时保持抓握；这不会放宽退出位移或累计转角验收。

交接到搬运阶段前必须确认实际螺丝尖端已越过初始孔口至少 0.1 mm，累计旋出角的容差收紧到 0.05 rad。控制器对 58.5 mm 退出行程继续沿真实螺纹导程旋转。搬运时利用两头螺纹及六角头相差 π 的物理等价相位：每个候选都检查搬运和后续完整旋入路径，IK 或碰撞不通过的候选会保存拒绝原因，选择另一可执行候选。初始化预检和运行时使用同一个私有原生接触门控，运行时同样不写入物体坐标。

## 命令入口

在服务端目录，使用已安装 Basilisk 的同一 Python 环境。先做原生动力学检查，再录制；将路径替换为实际场景与输出目录：

```bash
python tools/run_scripted_task.py --task aviation_bolt_insert --scene /absolute/scene.json --output /absolute/bolt-dynamics
python tools/run_scripted_task.py --task locking_rod_cycle --scene /absolute/scene.json --output /absolute/rod-dynamics
```

单条正式双相机录制：

```bash
python tools/record_threaded_task.py --task aviation_bolt_insert --scene /absolute/scene.json --output /absolute/bolt-recording --episodes-root /absolute/episodes --offline
```

批量采集（另一个任务使用 `--task locking_rod_cycle`）：

```bash
python tools/collect_threaded_tasks.py --task aviation_bolt_insert --scene /absolute/scene.json --output /absolute/bolt-batch --episodes-root /absolute/episodes --count 5 --max-attempts 15 --seed 20261026 --offline
```

随机布局增加 `--layout-pool /absolute/layout-pool.json`，相机随机化使用既有 `--randomize-overview-camera`。完整运行配置、机构变体、初态拒绝、任务阶段、失败原因和逐帧真实机构状态都会保存到批次/单条记录中。

两个螺纹任务默认允许 900 秒仿真时间，给多圈旋拧与自然回腕重抓留足时间；其他任务原有默认值不变。可用 `--max-sim-seconds` 显式缩短/延长诊断或单条录制。螺纹任务本次录制的帧上限至少为 `ceil(仿真时长 × 50) + 1`，默认 45001 帧；此覆盖会记在场景和录制报告中，不修改全局 `config/recording.json`。正式录制的墙钟超时默认 5400 秒。

## 验收

原生动力学测试不包含相机训练数据；正式采集仍要求 50 Hz、两路 RGB、1024×1024、七维训练状态/动作和 200 Hz 六维腕力。双相机、时戳、帧配对、视频解码和 LeRobot 原始数值沿用统一验收。

航空螺丝必须实际完成初始孔退出位移及累计旋转，并在目标孔达到要求的累计旋转、轴线、径向和落座误差。允许完整的多次回腕重抓序列；缺少旋出、搬运或旋入阶段的录像拒绝。

旋入交接到松爪时，实际累计转角距离要求值最多差 0.02 rad；最终松爪后的累计转角容差仍为 0.15 rad，用于容纳真实卸载回弹。撤离路径继续将夹爪打开到 0.75 rad，验证阶段保持这个开度，不能重放先前未完成的局部松爪轨迹。

实际手指脱离后优先沿目标孔轴向上抬 10 cm，同时继续张开夹爪；不会沿旋拧后的任意水平朝向扫过邻件。上抬路径不可达或碰撞时，才检查连续斜上退出候选。完整初始化预检包含松爪与撤离；这两段不允许非指尖机械臂与环境产生负间隙。运行时撤离在私有模型中恢复完整实测坐标和四杆被动关节偏差，再检查全部路径，不改变正式仿真状态。

杆状机构必须实际旋松、脱离挂钩、接触卡扣、扶起复位并旋紧。拧紧后同时检查铰链角、紧固件位移/转角的螺旋关系、挂钩接触及实际法向反力；只靠“到过目标位置”不能验收。接触反力来自原生接触力只读接口，缺少此证据时不能声明旋紧成功。

两项任务最终都必须在手指脱离后保持稳定。失败录像可以保留用于诊断，只有完整通过动力学与数据验收的记录进入批次成功列表。实现接入与运行验收是两个独立结果，实际通过情况应以对应运行目录的 `summary.json` 和 `validation.json` 为准。

v2 还保存 200 Hz 指令连续性统计 `reference_motion_quality`。采集验收要求
机械臂参考速度不超配置、加速度不超过 1 rad/s²、阶段交接单步速度变化不
超过 0.00501 rad/s；旋拧样本至少 95% 有双侧卡口扣合，最大腕轴偏差小于
0.05 rad，每次重新旋拧都必须有实际扣合证据。jerk 峰值同时记录供审查。
这些是机械臂参考和扣合检查，不是腕力超载停止；实际接触脉冲另行保留。
