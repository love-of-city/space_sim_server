# 双臂卫星与视觉抓取实验代码快照

本次按用户要求提交当前双臂卫星实验代码与配套模型、UE 资产。包含相邻面双臂、四 L 爪及软垫、真实 X 接口开窗碰撞、整星质心同轨初始化、逐视角工作灯与中键观察、末端相机和四靶标的图像位姿解算、实时误差面板，以及默认关闭的短程视觉控制试验。

短程试验只将原始末端 PNG 解算结果用于控制，关节反馈用于坐标转换；仿真目标真值仅记录到独立评分文件。识别失败、过期或场景不一致时停止运动。既有完整抓取脚本仍包含真值定位基线，不能将其结果描述为完整视觉抓取验收。

本地视觉试验：约 500 至 480 mm 的短程靠近完成，143 帧评分的位置误差 95% 分位为 1.55 mm、姿态误差为 0.462 度；150 mm 静态观察 19/19 帧有效，50 mm 静态观察 0/24 帧有效。近距靶标离开视场，尚未完成完整视觉抓取。丢失后结合运动反馈预测、接触后力控的完整抓取方案尚未在本次快照中实现或验收。

正常启动不自动执行抓取。实验的运行实例、日志、认证数据库、图片与录制仍留在本机，不提交机器状态或用户凭据。模型 SHA256 为 `1485987b90df5eff177743fbe6d34985d262f56dfa94b676d6c62627d3867c9c`；本次整理推送不修改其质量、惯量或物理定义。

推送前同时补齐视觉测试的 CI 依赖、精确记录 Basilisk 原生测试的基础 CI 排除范围，并更新旧模板、贴图和采样状态断言以覆盖新增功能。原始输入包的字节通过 Git 属性保留，模型和 UE 二进制资产通过 Git LFS 管理。基础测试不代表 UE 全流程、硬件视觉或完整抓取验收。
