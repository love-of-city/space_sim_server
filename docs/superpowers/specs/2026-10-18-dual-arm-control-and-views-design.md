# 双臂场景控制、外观及抓取视角修正

日期：2026-10-18
状态：设计待确认，尚未实施本轮修改。

## 已确认需求

目标星在服务星附近以相对静止状态开始；保留各星自己的质量、惯量和真实接触响应。抓取臂相机右侧增加主视口小窗。底部抓取臂的连杆外形、关节外壳及材质与原操作臂一致，保留四 L 爪末端。新增抓取臂可以像原操作臂一样控制移动。

## 当前实现与问题

- 保存实例已有 target_relative_velocity_m_s=[0,0,0]。初始化器以服务星线速度加此偏移设置目标星速度；不能仅将旧 target_linear_velocity_m_s 清零。
- 目标星角速度单独设置，初始化验证未统一输出两星相对姿态变化和相对角速度。需要以同一坐标系检查，而不是根据屏幕运动猜测。
- Capture26Component 持续发布 12 个固定关节参考，新增六轴被保持在折叠状态。这是当前不能控制的直接原因。
- 原操作臂和新增臂分别引用 SARM_mjcf_20261012 与 dual_arm_capture26 网格，新增臂显示色为蓝灰。需复用原臂资产及其坐标变换，不能只替换颜色。
- 当前网页只有一个活动视频播放器；UE 主视口的小窗不是所有相机流自带的布局。

## 方案

### 初始相对状态

保留两星位置间距和各自质量、惯量。初始化时显式匹配线速度，并在统一惯性坐标系匹配角速度；当前零角速度工况下为两者均零。若后续允许非零服务星角速度，以 v_target=v_service+omega_service×r 的条件构造服务星坐标系中的零相对速度。两星姿态不要求数值相同，保留目标接口的安装朝向。

从权威状态输出初始相对位置、相对线速度、相对角速度，验证无控制输入和无接触时的短时变化。区分初始静止与持续编队保持；不加入 weld、不逐帧覆写目标速度、不偷偷关闭引力差或碰撞。

### 抓取视角右侧主视口小窗

抓取臂末端相机作为大画面；右侧叠加标有“主视口”的小画面，通过独立只读视频连接显示已有主视口流。小窗不转发机械臂操作输入，避免一个按键进入两个控制通道。切离抓取相机时释放小窗连接，断线/场景停止时明确显示无信号，不保留伪实时旧帧。主视口小窗内的中键只控制该主视口的观察偏移；点击小窗可将主视口选为大画面。相机原始位姿及各灯独立状态不变。

### 抓取臂外观

复用原操作臂六个连杆和关节外壳的网格与 UE 材质映射，保持底面安装座、完整六轴链和新抓夹。逐节核对网格局部坐标与机械关节坐标，避免网格交换后轴心错位。保持已有惯性参数；如真实结构参数需要更新，另列报告，不以外观更新名义覆盖。碰撞体与新外形偏差需报告和修正，保留原折叠模型备份并检查底面安装、展开与自碰撞。

### 双臂控制

增加明确的“操作臂 / 抓取臂”选择，与相机下拉选择分离。默认仍为原操作臂。选择抓取臂后，现有键盘/手柄六维末端指令驱动抓取臂六关节；使用抓取臂自己的运动学、限位、执行器和反馈，不能把原臂关节索引直接重用。

前后端 action 和 observation 增加臂标识及相应能力标志；兼容旧单臂场景。切臂、失焦、断线、超时和急停先清零运动输入；未选中的臂保持当前位置，禁止回跳到初始折叠角。关节角、末端位置和控制状态显示与当前所选臂一致。新抓夹开合与轴向伸缩使用独立明确的控件，不将旧四连杆夹爪命令误用于新机构。此次不宣称自动抓取成功。

## 涉及模块

- simulation/teleop_grasp_unreal.py：初态验证、双臂实例与状态采样。
- simulation/components/capture26.py：由恒定目标保持改为可控且可保持的抓取臂参考。
- backend/space_arm_platform/models.py 及控制路由：带臂标识的动作和遥测。
- frontend/app.js、视频连接模块及 index.html：双臂选择、关联反馈、只读小窗与输入隔离。
- model/SARM/platform/sarm_dual_capture26.xml、manifest 和 UE 资产目录：统一外观、记录验证后的哈希。

## 验收

1. 两星初始相对速度、角速度以同一参考系实测验证，质量/惯量和姿控配置对比不变。
2. 新相机大画面和主视口小窗同时更新，切换/断线后不会遗留控制输入或旧帧。
3. 两臂连杆和关节外壳资产、材质一致，新抓夹保留；折叠/小角度运动无明显安装干涉。
4. 抓取臂六维输入能产生对应末端运动；原操作臂不被错误驱动。切臂后保持实测当前位姿。
5. 失焦、急停、超时、断线、切臂及限位都有针对性测试。
6. 前后端必要测试与 UE 编译通过后，在实际 MuJoCo/Basilisk + UE 场景中运行演示，保存截图和关键实测结果。静态测试不替代运动验收。
